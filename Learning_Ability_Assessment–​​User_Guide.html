一、系統啟動與環境說明

本系統特別為教學現場最佳化，無須安裝 Python 或資料庫軟體，只要是 Windows 系統即可解壓即用，並提供完全獨立的視窗介面，不受瀏覽器其他分頁干擾。

1
一鍵免安裝啟動

進入資料夾後，直接雙擊 啟動系統.exe（或 啟動系統.bat）。系統會在背景自動啟動高速本地伺服器，並以專用獨立 App 模式開啟視窗。

2
選擇角色模式

首頁提供兩大核心模式：

  • 👨‍🏫 教師教學模式：適合投影到大螢幕／電子白板，利用課堂 5~10 分鐘零碎時間挑題講解、搭配白板筆圈題與英語單題跳播。
  • 🧑‍🎓 學生測驗模式：學生自主進行全真模擬測驗、隨堂計時填答、自動批改評分與成績診斷分析。

💡 提示：關閉視窗時，若需要完全停止背景伺服器，只需在黑色背景控制台視窗按下 Ctrl + C 或直接關閉該控制台即可。

二、👨‍🏫 教師教學模式指南

教師教學模式專為課堂投影與大屏互動設計，支援快速篩選題庫、整頁/單題雙檢視切換，讓老師能在有限的課堂時間內精準施教。

🔍 1. 題庫篩選與搜尋

  • 年度切換：預設包含 115 年度題庫，亦可透過在線擴充下載歷史試卷。
  • 年級與科目：涵蓋國小三年級至國中八年級之國語、數學、英語（含英聽）、自然等考科。
  • 關鍵字搜尋：支援依題型或單元名稱即時模糊篩選。

👁️ 2. 全頁瀏覽 vs 單題聚焦雙模式

  • 全頁瀏覽模式：完整還原官方 PDF 原始排版與圖文情境，適合引導學生閱讀長篇文章或跨頁題組。
  • 單題聚焦模式：點擊右側題目列表的任一題號，系統立即裁切出該題高解析圖檔並置中放大，排除其他干擾，引導全班集中注意力。
  • 縮放與自適應：提供 放大 (+)、縮小 (-) 及 最適寬度 功能，因應不同尺寸的觸控電視或投影幕。

三、🖍️ 白板筆與課堂互動工具

全螢幕或單題聚焦時，畫面下方提供懸浮式【教學互動工具列】，無論使用滑鼠、觸控筆或電子白板手指觸控皆可靈活書寫。

工具按鈕 功能說明 教學應用情境
🖍️ 白板筆 普通實心筆刷，可切換紅/藍/黑/綠及自訂筆觸粗細。 標記關鍵字、題目線索、計算過程推導。
🖊️ 螢光筆 半透明亮色筆刷，不遮擋題目文字與幾何圖形。 圈選題幹重點條件、文章主旨句。
🧹 橡皮擦 局部擦除筆跡，或點擊「清空」一鍵清除全版。 修改演算錯誤或換題時一鍵重置畫面。
⏱️ 計時器 倒數計時工具，支援 30秒、 1 分鐘、3 分鐘。 課堂限時思考、分組競答、隨堂抽測作答時間掌控。
💡 解析與答案 點擊即時展開正確選項與官方解題說明(如有提供)。 引導學生思考完畢後，即時公布解答並核對觀念。

四、🎧 英語聽力精準播放與跳轉

以往英語聽力測驗教學最耗費時間在「尋找題目音檔位置」。本系統特別強化了英聽播放引擎：

A
選題自動對齊播放

當選擇英語聽力試卷並點擊特定題號時，播放器會精準載入該題裁切音訊，不再每次從整份試卷的第 0 秒重頭播放。

B
高精準進度拉桿與秒數微調

播放介面配備：

  • 時間軸拖曳拉桿：隨點隨跳，即時反應。
  • 秒數手動輸入：可直接鍵入目標秒數（如 12.5 秒）並按下「切換」，精準跳至題目問句或選項重複念讀點。
  • 快退 / 快進按鈕：支援 -5秒 與 +5秒 微調，方便反覆聆聽聽力關鍵字。

五、🧑‍🎓 學生自主練習與模擬測驗

提供學生全真線上測驗體驗，幫助學生適應電腦化測驗流程，建立自信。

📝 測驗三部曲操作流程

1
選卷與進入測驗

點擊首頁「進入學生練習」-> 選擇欲練習的年度、科目與年級 -> 點選「開始測驗」。

2
作答與題號導覽

  • 填答選項：點選右側的選項圓圈 (1)、(2)、(3)、(4) 即時記錄答案。
  • 題號速覽面板：綠色標記已作答題，灰色為未答題，可隨時點擊任意題號快速跳題檢查。
  • 測驗計時：右上角即時顯示測驗已用時間，培養學生的時間分配能力。

3
交卷與診斷報告

作答完成點擊「交卷」，若有未填寫題目系統會友善提醒；交卷後立即產生：

  • 總得分與正確率。
  • 每題對錯清單：清楚對照「你的答案」與「正確解答」。
  • 點擊查看錯題解析：立即複習迷思觀念。

六、🌐 教室／校園區域網路連線教學

特別適用於電腦教室或班級平板課！老師的主機啟動後，學生端不用安裝任何程式，只要打開瀏覽器輸入教師機 IP 即可全員同步上線。

📶 區域網路三步驟連線教學

  1. 教師機啟動：在教師電腦點擊 啟動系統.exe。
  2. 查詢教師機 IP：
    • 按鍵盤上的 Win + R 鍵，輸入 cmd 並按 Enter。
    • 在出現的黑色視窗中輸入 ipconfig，找到 IPv4 位址（例如：192.168.1.108）。
  3. 學生平板/電腦直接連線：
    • 學生打開 Chrome 或 Edge 瀏覽器，在網址列輸入：http://192.168.1.108:8080（請將 IP 替換成您的教師機 IP）。
    • 立刻進入系統！每位學生的測驗紀錄會保存在學生自己的裝置上，完全互不干擾。

七、💾 資料備份與隱私管理

本系統基於瀏覽器標準 IndexedDB 技術，所有學生的作答歷程、錯題分析完全儲存在裝置本地，無上傳外部雲端洩漏個資之風險。

⚙️ 系統資料維護功能

  • 匯出備份 (Export)：點擊「匯出資料」可將個人測驗歷史儲存為 .json 檔案，方便換電腦移轉紀錄。
  • 匯入還原 (Import)：點擊「匯入資料」並選擇備份檔案，即可恢復所有歷史練習成績。
  • 清除資料 (Reset)：若使用公共電腦，離開前點擊「清除個人資料」，即可秒速抹除所有本機瀏覽與測驗軌跡，保護個人隱私。

八、❓ 常見問題與疑難排解 (FAQ)

Q1. 雙擊「啟動系統.exe」後被 Windows 防火牆或防毒軟體阻擋怎麼辦？

A：這是因為自建本地伺服器需要監聽 8080 連接埠。請在 Windows 提示視窗中點擊「其他資訊」->「仍要執行」，並勾選「允許專用網路存取」即可放心使用。

Q2. 英語聽力沒有聲音或是音檔載入逾時？

A：請檢查電腦是否已開啟喇叭音量。若點擊播放後逾時，畫面會出現重新載入提示按鈕，請點擊「重新載入音訊」，或手動拖動時間拉桿即可恢復播放。

Q3. 學生測驗模式題目字體太小看不清楚？

A：測驗介面上方附有 🔍 縮放控制項（+ / -），或者可以直接按住鍵盤 Ctrl 滾動滑鼠滾輪進行畫面放大。

Q4. 如何將題庫更新或擴充到更多年度？

A：在題庫大廳遇到標示「雲端題庫」的試卷時，可以直接點擊「載入至本機題庫 (IndexedDB)」，系統便會自動將題目圖片與聽力音檔存入瀏覽器快取，狀態切換為綠色「已就緒」後即可離線使用。若點擊後彈出生成指引，表示本機尚未解析該份原始題本，此時需在專案終端機執行 python 命令(作業系統須具備 python 環境)。程式會自動自官網下載 ZIP 壓縮檔、解開 PDF 並完成高解析度裁切與答案抽取，執行完成後重新整理網頁即可載入作答。
