在開始部署前，請確認本專案目錄下已具備以下四大關鍵程式檔案：

1. appsscript.json

專案設定檔，負責定義台北時區 (Asia/Taipei) 與 Google Drive / DocumentApp 的合法存取權限範圍。

2. HandbookData.gs

手冊官方出廠資料庫，收錄 8 大類 20 個完整案例 SOP、話術金句、陳情調和與三大支持系統。

3. Code.gs

後端主程式，處理 Web App 網頁派送、精準檢索引擎、Gemini 模型整合、管理員修訂存檔與 Google 文件生成。

4. Index.html

前端 RWD 響應式網頁介面，支援手機與電腦查閱、管理員中心 Modal、自訂模型與 API Key 記憶。

1

步驟一：登入 Google 並建立全新 Apps Script 專案

1. 開啟瀏覽器，前往 Google Apps Script 官方首頁 (script.google.com)。

2. 登入您的 Google 帳戶（個人 Gmail 帳號或學校 Google Workspace 教育版帳號皆可）。

3. 點選畫面左上角的 「＋ 新專案」（New project）藍色按鈕。

4. 進入編輯器後，點擊左上角的「未命名專案」，修改專案名稱為：臺南市合理管教全攻略手冊查詢系統，然後按下「重新命名」。

2

步驟二：設定專案資訊清單 (appsscript.json)

此設定檔用以授權建立 Google 文件及讀寫雲端硬碟自訂資料庫：

操作流程：

  1. 點擊左側導航欄最下方的 「專案設定」（齒輪圖示 ⚙️）。
  2. 在「一般設定」區塊中，勾選 「在編輯器中顯示『appsscript.json』資訊清單檔案」。
  3. 點選左側最上方的 「編輯器」（<> 圖示）返回檔案列表。
  4. 此時左側檔案清單中會出現 appsscript.json，點擊開啟它。
  5. 將原本內容完全刪除，覆蓋貼上以下 JSON 內容並按 Ctrl + S 儲存：
{
  "timeZone": "Asia/Taipei",
  "dependencies": {},
  "exceptionLogging": "STACKDRIVER",
  "runtimeVersion": "V8",
  "oauthScopes": [
    "https://www.googleapis.com/auth/documents",
    "https://www.googleapis.com/auth/drive",
    "https://www.googleapis.com/auth/script.external_request"
  ]
}
3

步驟三：建立並依序貼上三大核心程式檔案

【複製代碼防呆提醒】

複製各檔案內容時，請直接點擊代碼檔案右上角複製，或在檔案內使用 Ctrl + A 全選後 Ctrl + C 複製，避免滑鼠手動框選時漏掉結尾的大括號 }，以防出現 SyntaxError: Unexpected end of input 錯誤。

1 建立 HandbookData.gs (資料庫模組)

  1. 點選左側「檔案」旁邊的 「＋」 按鈕，選擇 「指令碼」 (Script)。
  2. 將檔案名稱命名為：HandbookData（系統會自動加上 .gs）。
  3. 將您自核心檔案套件中解壓縮出的 HandbookData.gs 全部內容複製貼入編輯器中，按 Ctrl + S 儲存。

2 貼上 Code.gs (後端服務邏輯)

  1. 點選左側原本預設的 「程式碼.gs」（亦可右鍵重新命名為 Code）。
  2. 將編輯器內的預設程式碼全部刪除清空。
  3. 將您自核心檔案套件中解壓縮出的 Code.gs 全部內容複製貼入，按 Ctrl + S 儲存。

3 建立 Index.html (前端網頁介面)

  1. 點選左側「檔案」旁邊的 「＋」 按鈕，選擇 「HTML」。
  2. 將檔案名稱命名為：Index（系統會自動加上 .html）。
  3. 將編輯器內的預設內容全部清空。
  4. 將您自核心檔案套件中解壓縮出的 Index.html 全部內容複製貼入，按 Ctrl + S 儲存。
4

步驟四：新增網頁應用程式 (Web App) 部署作業

1. 點擊編輯器右上角大大的藍色按鈕 「部署」 ➔ 點選 「新增部署作業」。

2. 在彈出的部署面板中，點選左上角的 「選取類型」（齒輪圖示 ⚙️）➔ 選擇 「網頁應用程式」 (Web App)。

3. 部署參數設定（非常關鍵，請務必依下方填寫）：

  • 說明：輸入 教師合理管教全攻略查詢系統 v1.0
  • 執行身分：請選擇 「我 (您的電子郵件)」
    （這樣系統存取自訂資料庫與產生 Google 文件時，均由您的後端代理執行，老師不需各別設定資料夾權限）。
  • 誰可以存取：務必選擇 「所有人」 (Anyone)
    （若未選所有人，其他老師打開網址會跳出「需要存取權」或 403 錯誤而無法使用）。

4. 點擊面板右下角的 「部署」 按鈕。

5

步驟五：完成 Google 帳號授權（通關「不安全」警示畫面）

初次部署時，Google 會要求授權應用程式存取您的 Google 雲端硬碟以儲存資料庫及生成文件：

①
彈出「需要授權」視窗，點選 「審查權限」 (Review permissions)。
②
選擇您的 Google 帳戶登入。
③
出現「Google 尚未驗證這個應用程式」警示畫面（正常現象）：
點選左下方不起眼的淡灰色小字 「進階」 (Advanced) 展開說明。
④
點選最下方出現的連結：
前往『臺南市合理管教全攻略手冊查詢系統』(不安全)。
⑤
檢視所要求的權限（查看、編輯 Google 文件與雲端硬碟檔案），點選右下方藍色的 「允許」 (Allow)。
6

步驟六：取得正式網頁應用程式網址並發布

1. 完成授權後，畫面會顯示「部署作業已成功更新」。

2. 找到 「網頁應用程式」 底下的 「網址」，點擊右邊的「複製」按鈕。

正式網址格式範例：

https://script.google.com/macros/s/AKfycby.../exec

請將這段網址加入瀏覽器書籤、發布至學校校園首頁、群組公告，或轉成 QR Code 張貼於各學年辦公室，供全校教師隨時利用手機或電腦掃描查閱！

7

重要須知：未來修改程式碼後的「版本更新」發布流程

【90% 使用者常犯錯誤】：

在 GAS 編輯器中修改完程式碼並存檔後，外部網頁不會自動更新！若直接重新整理網頁應用程式，仍然會讀取舊版代碼。您必須執行以下 4 個小動作發布「新版本」：

  1. 點擊編輯器右上角的 「部署」 按鈕 ➔ 選擇 「管理部署作業」。
  2. 在左側選中目前生效的網頁應用程式，點擊右上角的 「鉛筆圖示」（編輯）。
  3. 在「版本」下拉選單中，點選 「建立新版本」 (New version)。
  4. 點擊右下角藍色的 「部署」 按鈕完成更新。

* 採用此標準方式更新時，網頁的 URL 連結網址完全不會改變，老師使用的書籤與 QR Code 依然持續有效！

8

常見問題與疑難故障排解 (Troubleshooting)

Q1：其他人點開網址出現「抱歉，目前無法開啟這個檔案」或要求登入？

原因：部署時「誰可以存取」未設定為「所有人」。
解法：點選「部署」➔「管理部署作業」➔ 編輯 ➔ 將「誰可以存取」改為「所有人」➔ 建立新版本 ➔ 重新部署。

Q2：儲存 Code.gs 時出現「SyntaxError: Unexpected end of input」？

原因：複製代碼時中斷，漏掉了最後面的大括號 }。
解法：請直接在本機以文字編輯器打開 Code.gs，按下 Ctrl + A 全選後複製貼上覆蓋。

Q3：點擊「在雲端建立 .gdoc」按鈕時提示錯誤或權限不足？

原因：未正確更新 appsscript.json 或未給予 Google Docs / Drive 權限。
解法：請回到「步驟二」確認 appsscript.json 內容完全貼妥，並在編輯器中執行一次 doGet 觸發重新授權。
