第二步：開啟 Apps Script 並貼上 Code.gs

部署負責處理資料讀寫、身分驗證與動態建表的後端核心

  1. 在剛建立的 Google 試算表上方選單，點選 「擴充功能」 ➔ 「Apps Script」。
  2. 將專案標題（左上角「未命名專案」）修改命名為「智慧校務行政整合系統」。
  3. 在左側檔案清單中點擊 Code.gs。
  4. 將編輯器內的預設程式碼全部清空（按 Ctrl + A 全選後按 Delete）。
  5. 點擊上方產生器的 「一鍵複製 Code.gs 後端代碼」，完整貼入編輯器中。
  6. 按下鍵盤 Ctrl + S（Mac 為 Cmd + S）儲存。

第三步：建立前端網頁檔案 Index.html

部署全校同仁、主管與訪客查閱之響應式現代化校務介面

  1. 在 Apps Script 編輯器左側「檔案」旁邊，點擊 「+」按鈕 ➔ 選擇「HTML」。
  2. 檔名請直接輸入 Index 並按下 Enter（系統會自動建立為 Index.html）。
  3. 將新建立的 Index.html 編輯區內預設代碼全部清空刪除。
  4. 點擊上方產生器的 「一鍵複製 Index.html 前端代碼」，完整貼入 Index.html 中。
  5. 按下鍵盤 Ctrl + S 儲存。

第四步：發布部署為 Web 應用程式 (關鍵上線步驟)

產生專屬網址，供全校師生與行政同仁使用

  1. 點擊 Apps Script 視窗右上角的深藍色按鈕 「部署」 ➔ 選擇「新增部署作業」。
  2. 在彈出的對話框中，點擊左上角 齒輪圖示 ➔ 選擇「網頁應用程式 (Web App)」。
  3. 確認並完成下列三項核心參數設定：
    部署說明：校務整合系統正式上線 v1.0
    執行身分：我 (您的 Google 帳號)
    誰可以存取：所有人 (Anyone)

    ⚠️「誰可以存取」務必選取「所有人」，這樣學校同仁與訪客無需擁有試算表編輯權限，即可直接檢視前台！

  4. 點擊 「部署」 按鈕，系統將要求授予讀寫試算表之權限：

    🔐 Google 原廠授權驗證指引（首次部署專屬流程）：

    1. 點擊「審查權限 (Review permissions)」並登入您的 Google 帳號。

    2. 若畫面出現「Google 尚未驗證這個應用程式」，請點擊左側小字 「進階 (Advanced)」。

    3. 點擊最下方 「前往『智慧校務行政整合系統』(不安全)」。

    4. 點擊 「允許 (Allow)」 即可完成官方權限綁定。

  5. 部署完成後，複製畫面上產生的 「網頁應用程式網址 (Web App URL)」，這就是您的全校專屬入口網址！

💡常見問題與系統維護說明 (FAQ)

Q1. 我後續修改了 Code.gs 或 Index.html 程式碼，為什麼網頁沒有更新？ ▼

Google Apps Script 修改程式碼儲存後，必須執行「更新部署作業」才能對外生效：

  1. 點擊右上角藍色 「部署」 ➔ 「管理部署作業」。
  2. 點擊右上角鉛筆圖示（編輯）。
  3. 在「版本」下拉選單中，務必選擇 「新版本 (New Version)」。
  4. 點擊右下角 「部署」 按鈕即刻生效，網址保持不變！
Q2. 學校同仁或家長使用手機瀏覽時，需要登入 Google 帳號嗎？ ▼

完全不需要！只要在部署時設定「誰可以存取：所有人 (Anyone)」，任何同仁無論使用手機、平板或電腦，點開連結皆可直接瀏覽公開之公告、榮譽榜與常用網站。

Q3. 校務資料儲存在哪裡？是否有資料外洩風險？ ▼

所有資料全部存放於您第一步所建立的 Google 試算表中，屬於學校或發布者專屬的 Google 帳號所有。沒有經過您的密鑰驗證，任何人都無法在網頁端增修資料，安全性由 Google 原廠最高規格保護。

Q4. 如何新增其他業務模組（例如設備報修、校車登記或場地預約）？ ▼

本系統特別設計了「自訂擴充工作表」引擎。管理員登入後前往「📁 自訂擴充項目」標籤，點擊「📄 建立全新工作表」，輸入自訂欄位名稱（如：報修日期, 地點, 故障項目, 報修人），系統就會全自動在試算表插入新分頁並在前台產出專屬表單與維護表格！
