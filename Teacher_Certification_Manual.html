第一章 設計理念與核心願景

1.1 研發背景與考生痛點分析

每年參加教育部「高級中等以下學校及幼兒園教師資格考試」（教師檢定）的實習生與師資生高達數萬人。然而傳統的考古題複習面臨諸多痛點：

❌ 試題分散難以檢索

歷屆試題散落在數十份 PDF 中，試題本與參考答案分開存放，核對極度耗時耗神。

❌ 題組文章閱讀體驗極差

長篇閱讀測驗動輒上千字，一般網頁必須頻繁上下滾動，嚴重打斷作答思路與解題專注力。

❌ 資訊過載缺乏單科專注

多數考生僅報考國小、中等、幼兒園或特教其中一種，強行載入全科會造成記憶體臃腫與操作困擾。

❌ 口試試教缺乏念稿排版

筆試通過後緊接著是面試試教，需要朗讀擬答訓練語感，一般題庫系統字體過小無法做為念稿工具。

1.2 四大核心設計哲學

  • 零後端（Zero-Backend）與離線優先（Offline-First）：純前端單一檔案架構，題庫、高解析圖片、WebAssembly SQLite 與圖表引擎全數內嵌，下載單一 HTML 即可離線永久使用。
  • 認知卸載（Cognitive Offloading）：排除多餘視覺雜訊，透過「🧘 極致專注模式」、題組長文摺疊與手機懸浮抽屜，將考生的注意力完全釋放至深度知識提取。
  • 考科自主瘦身（Single-Category Optimization）：內建題庫管理員，一鍵剔除其餘無關考科，專為報考類科提供毫秒級的極速反應。
  • 念稿與試教口說雙用（Speech-Ready Typography）：首創 4 段級距式字體縮放，提供專為朗讀訓練打造的 28px 巨字排版與 2.15 倍行距，無縫銜接教師甄試複試準備。

第二章 系統架構與技術運作原理

2.1 單一檔案 Web App (SFA) 架構全景

系統突破傳統網頁應用程式對後端 API 伺服器與資料庫主機的依賴，採用先進的單一檔案封裝技術：

[Teacher_Certification.html]
├── HTML5 結構層 (儀表板 / 練習區 / 專注浮動條 / 題庫管理 Modal)
├── Tailwind CSS + Custom Typography (原子化 CSS + 4段念稿字級樣式)
├── WebAssembly SQLite (sql.js 1.10.3) + Chart.js 圖表引擎
├── Pako.js 2.1.0 (zlib/deflate 前端即時解壓縮)
└── COMPRESSED_EXAM_DATA (5.6MB Base64 內嵌高密度全量題庫)

2.2 數據層雙軌運作機制

軌道一：內建記憶體資料集 (In-Memory)

檔案開啟時，initBuiltInDataset() 透過 atob() 與 pako.inflate() 在瀏覽器記憶體中將 Base64 字串瞬間還原為 2,927 道去重題目 JSON，耗時僅約 50～80 毫秒，實現完全離線免伺服器。

軌道二：WebAssembly SQLite 動態掛載

點擊「📂 載入 .db 題庫」時，啟動 sql.js 引擎，直接在瀏覽器記憶體中以二進位 ArrayBuffer 掛載 SQLite 資料庫，執行標準 SQL 語法查詢並動態替換題目。

2.3 本機持久化存儲模型 (localStorage)

系統所有作答紀錄皆嚴格保存在考生本機端，無個資洩露風險：

Key 名稱 儲存結構 功能描述
teacherExamUserRecords JSON Array 歷次刷題與模考 session 紀錄（答題數、正確率、耗時）
teacherExamUserMistakes JSON Object 錯題本字典，紀錄每題的答錯次數、連續答對數與口訣筆記
teacherExamFontLevelIdx Integer (0~3) 儲存使用者偏好的排版字級（0:標準, 1:大字, 2:特大, 3:念稿巨字）

第四章 完整功能模組深度使用指南

4.1 師資類科切換與選單連動

點擊頂部【幼兒園】、【國民小學】、【中等學校】、【特殊教育】膠囊標籤，系統即刻自全量題庫中進行動態過濾，同時更新歷年試卷清單、考試科目選單，並將共同考科（國語文）自動映射歸屬。

4.2 學習儀表板（Dashboard）與歷年試卷卡片

  • 總體學習 KPI：即時統計目前類科累計作答數、正確率、錯題複習進度。
  • 弱點概念雷達：自動分析答錯頻率最高的知識點標籤（如 `#課程評鑑`、`#艾瑞克森心理社會期`）。
  • 歷年試卷卡片（Exam Cards Grid）：依年度由新至舊（115→110年）完整排列。每張試卷卡片皆具備：
    • 📝 循序刷題：照題號循序練習，可即時查看詳解。
    • ⏱️ 全真模考：進入官方 80/100 分鐘倒數計時模擬考，模擬真實考場情境。

4.3 刷題與全真模擬（Practice & Mock Exam）

主介面分為左側「試題卡片」與右側「答題進度卡」：

  • 選擇題作答：點選選項按鈕或使用鍵盤 1～4、A～D 快速劃記。
  • 非選擇題擬稿與自評規準：提供打字作答框（自動計字）。點擊「👁️ 顯示高分擬答」展開官方給分規準，支援四階自評（需加強 30% / 部分掌握 60% / 良好 85% / 完全精熟 100%）。低於 70% 自動加入錯題本。
  • 鍵盤快捷鍵：←（上一題）、→（下一題）、F（專注模式）、Esc（退出專注）。

4.4 🧘 極致精簡專注模式（Zen / Focus Mode）

一鍵排除干擾，享受沉浸式刷題：

✨ 專注模式核心特色：
• 啟用方式：點擊頂部橘色「🧘 專注模式」按鈕，或隨時按下鍵盤 F 鍵。
• 介面簡化：全域自動隱藏 header、導覽列、側邊題號抽屜及頁尾，視窗置中於適讀寬度（860px）。
• 三大護眼主題：支援切換「極簡純白」、「護眼暖米（Warm）」與「沉浸深黑（Dark）」。
• 隨手返回一般模式：提供 3 處返回按鈕（頂部浮動列右上角、題目卡片底部操作列、右下角懸浮膠囊），或按 Esc 鍵秒退回標準模式。

4.5 🔤 念稿大字排版模式（Speech & Large Text Mode）

專為口試面試與試教朗讀設計，點選頂部「🔤 字級」可循環切換：

1. 標準 (16px)
2. 大字 (19px)
3. 特大 (23px)
4. 🎙️ 念稿巨字 (28px)

切換為「念稿巨字」時，文字放大至 28px、行距擴增為 2.15 倍，段落清晰，即使站立在螢幕 1～2 公尺外進行口說背誦練習亦清晰可見。

4.6 行動端極致適配與閱讀文章抽屜

  • 觸控熱區最佳化：選項卡片加大 padding，直立手機單手點擊精準不誤觸。
  • 懸浮查看文章抽屜：遇到長篇閱讀測驗（如國語文題組、教育情境題），手機右下角會出現跳動的 「📖 查看文章」 按鈕，點擊立即滑出全螢幕文章抽屜，閱讀完畢關閉即可作答，不必在題目與文章間來回滑動。

4.7 錯題本與弱點消滅特訓（Mistake Book）

  • 熟練度機制：答錯自動收錄；在特訓中連續答對 3 次，題目狀態自動躍升為「已精熟」並自待加強清單中消滅。
  • 概念標籤特訓：可按標籤（如 `#班級經營`）集中發動「⚡ 啟動錯題消滅戰」。

4.8 歷屆試題檢索庫（Explorer）

支援年度、科目、大題類型複合檢索與全文關鍵字搜尋，檢索結果可一鍵「📝 在刷題練習中開啟」直接作答。

4.9 ⚙️ 題庫管理中心（Bank Manager）

• 🎯 類科瘦身：一鍵清除其他 3 類科題目，只保留目標考科（例如從 2,927 題精簡為國小 981 題），記憶體節省 66%，並可匯出專屬 JSON 題庫。
• 📥 擴充更多年度：直接上傳由 pdf_exam_extractor.py 產出的 JSON 或 SQLite 檔案，無縫擴展 109、108 年考古題。
• ➕ 手動新增／✏️ 編輯／🗑️ 刪除：可線上修正題幹解析或刪除已廢止之爭議題。
• 🔄 一鍵還原：隨時還原回 110–115 全類科官方完整題庫。

第五章 題庫自動化轉換與擴充工具

專案內建專用 Python 工具程式 pdf_exam_extractor.py，支援將官方試題本與答案 PDF 一鍵轉為本系統相容之 JSON 與 SQLite 檔案。

5.1 轉換指令語法

# 方式 1：互動引導模式（適合初學者，直接按提示輸入檔案路徑） python pdf_exam_extractor.py # 方式 2：單行指令批次轉換（指定試題本與答案檔） python pdf_exam_extractor.py -q "109_國小試題本.pdf" -a "109_國小答案.pdf" -o "109_國小.json" --db "109_國小.db" # 方式 3：指定年度與類科覆寫 python pdf_exam_extractor.py -q "試題.pdf" -a "答案.pdf" --year 109 --cat "國民小學" --subj "數學能力測驗"

5.2 匯入系統方法

  1. 產出的 .json 檔案：開啟 Teacher_Certification.html 點擊右上角「⚙️ 題庫管理」→「📥 擴充更多年度」→ 點選檔案即可完成匯入。
  2. 產出的 .db 檔案：點擊右上角「📂 載入 .db 題庫」選取檔案，直接以 WebAssembly SQLite 即時掛載。

第六章 常見問答與故障排除

Q1: 重新整理或關閉瀏覽器後，我的作答紀錄會消失嗎？
不會。所有紀錄儲存於瀏覽器 localStorage 中。建議考前點擊頂部「💾 匯出紀錄」備份為 JSON 檔案保存。
Q2: 遇到按鈕無反應或更新後畫面沒變？
請按下鍵盤 Ctrl + F5（Windows）或 Cmd + Shift + R（Mac）強制重新整理以清除瀏覽器快取。
Q3: 如何在筆電與手機之間同步錯題本？
在筆電點擊「💾 匯出紀錄」，將產生的 JSON 檔案傳到手機，在手機瀏覽器開啟系統後點擊載入，即可無痛繼承進度。
