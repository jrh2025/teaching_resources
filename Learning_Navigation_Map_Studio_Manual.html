第一卷

設計哲思與認知美學

PHILOSOPHY & PEDAGOGY

認知卸載：減去一切喧囂，回歸圖像本身（余白之美）

在傳統的數位地圖與教材軟體中，畫面往往充斥著密密麻麻的按鈕、側邊圖例表格以及底部晶片導覽條。這些看似提供引導的介面元素，在認知心理學上卻造成了嚴重的「認知超載（Cognitive Overload）」——學習者尚未看清地圖的地理肌理或藝術筆觸，視線就已被周遭冗餘的邊框與列表切割支離。

本軟體奉行日式美學核心的「余白（よはく，Yohaku）」精神。我們在最新版本中徹底移除了底圖右側的圖例面板與中央下方的底部導覽條，將完整的 100% 畫面主控權歸還於圖像。畫面開闊大氣，只有在滑鼠自然移入感興趣的地理特徵或景物標記時，標記才會輕柔浮動並散發溫潤微光；點擊時，一葉精緻的指向性氣泡視窗優雅彈出，帶出精準解說與清朗語音。

「最好的介面，是在你需要它時恰如其分地浮現，不需要它時則如空氣般靜默消融。」
空

空間記憶與錨定效應

人類大腦對「空間位置」的記憶力遠高於條列文字。透過在真實圖像上框選區域，將抽象知識「錨定」於具體地標之上，促使學習者建立直觀的心智地圖（Mental Map）。

「知其所自，明其所處」
聲
🗣️

世代權杖多感官通感

視覺、聽覺與指尖互動的通感融合。內建「世代權杖（Tokenized）分句語音引擎」，無論文章多長，皆能以自然的斷句呼吸流暢朗讀，打破閱讀障礙，長者與學童皆能自在聆聽。

「視之以形，聆之以音」

嚴格恪守原圖之真實比例（100% Native Aspect Ratio）。無論是 21:9 超寬全景、4:3 古地圖、1:1 方形切片或直式立式海報，絕不容許任何擠壓或扭曲變形。

「方正相稱，各得其宜」
通

摒棄繁複狹隘的專用測驗格式，回歸最通用的「標題、標籤、摘要、解說、照片、外鏈」。從國小地理到景區漫遊、從校園地圖到產品拆解圖，百業萬象皆能信手拈來。

「萬象包羅，大道至簡」

機能革新・新舊對比

EVOLUTION & ARCHITECTURE
設計構面 早期傳統樣板模式 本軟體・現代和風極致模式
版面與視覺重心 右側強佔寬度圖例面板、下方繁雜晶片條，圖片僅剩 50% 狹小視野。 100% 全幅滿版純粹視野，多餘圖例與底部導覽條完全移除，專注於圖像肌理。
底圖長寬比適應 強制擠壓或拉伸至固定的寬高比，直式海報或正方形圖嚴重變形。 原生長寬比自動適配引擎，16:9、4:3、1:1、9:16 直式海報等全無變形，標註點位百分比永久鎖定。
工具列操作體驗 固定在左側佔據大量寬度，圖示缺乏即時回饋，修改外觀需重複點開編輯表單。 即時外觀套用＋隨時一鍵隱藏，點選標註後點左側圖示立即變身，並附 ✕ / 🛠️ 自由收展。
內建示範地圖品質 粗糙的幾何方塊或缺乏細節的輪廓，無法作為正式示範教材。 內建官方精美「世界國家地圖」與「台灣縣市區域圖（含台澎金馬）」，完全收錄全球主要國家、各大洋洲（包含特別特大標記之「台灣」）與全台 22 縣市、三大離島、四大海域，共 55 處深度解析標註。
布景風格與氣質 單一暗黑冷硬色系，缺乏情境彈性與親和力。 6 種調和情境配色（蔚藍海洋、暖陽活力、翠綠自然、櫻花粉彩、復古羊皮卷、星際極光）。
語音朗讀穩定度 長文本朗讀容易卡頓或破音，缺乏分段自然呼吸感。 世代權杖標籤分句演算法，以標點符號自然換氣，支援音調速率微調與試聽。

極速操作完全手引

STEP-BY-STEP USER MANUAL
壹

免安裝・三秒極速啟動

本系統採用免安裝綠色設計，解壓縮後即可隨插即用。請先下載軟體檔案套件，再依照當前設備環境自由選擇啟動方式：

💡
雙擊「啟動學習導覽圖工作室.bat」或「學習導覽圖工作室.exe」：開啟獨立 Windows 桌面視窗，享受專屬檔案儲存對話框。
亦可直接以 Edge / Chrome / Safari 雙擊 index.html，跨系統（Mac/iPad/Chromebook）免安裝純瀏覽器運行！
📦 立即至 Google 雲端硬碟下載套件檔案
貳

底圖置入與智慧適配（支援各類長寬比）

點選左上角「🖼️ 更換底圖」，選取任何您自備的圖片（JPG、PNG、WebP、SVG 均可），或直接點選「🌏 精細世界」/「🇹🇼 精細台灣」使用內建的高階向量地圖。

📐
完全免調解析度：系統會自動讀取圖片寬高比並智慧計算畫布大小。即使是直式的景區摺頁海報或正方形 Instagram 圖片，都能 100% 等比呈現，絕無拉伸黑邊。
參

滑鼠拖曳框選標註・外觀即時切換

將滑鼠移至圖面目標景物上，按住滑鼠左鍵並拖曳出一個矩形框，放開後立即彈出編輯視窗！

🛠️
即時外觀套用：畫布上點選任一標註後，點擊左側工具列的圖示（⭕ 脈衝圓形、🥚 橢圓、▭ 圓角框、📍 編號圖釘），標註外觀瞬間即時變身！點擊左側最下方「✕」或頂部「🛠️」可隨時隱藏工具列。
肆

填寫標註內容（支援語音試聽與配圖）

表單經過極簡重構，僅保留最具通用價值的欄位： 標題名稱、分類標籤、副標題摘要、內文詳情解說、標註主題色、特寫配圖與外部延伸網址。

🔊
在編輯器中輸入解說文字後，可點擊「🔊 試聽語音」預覽朗讀效果。確認無誤後點擊「💾 儲存標註」（或鍵盤快捷鍵 Ctrl + S）。
伍

一鍵匯出獨立 HTML・隨處分享傳播

編輯完成後，點擊右上角「匯出獨立 HTML」按鈕。系統將自動產出一個單一、完整的 .html 網頁檔案！

🚀
單檔零依賴：底圖與標註資料已全部內嵌於該 HTML 檔中，無需伺服器、無需安裝任何軟體。直接將此檔案丟到隨身碟、上傳至 Google 雲端硬碟、以 LINE 傳送或放入教學平台，任何人點開即能沈浸式探索！

專業製作者常用快捷鍵 (Keybindings)

善用鍵盤快捷鍵，能讓您的編製流程如同揮灑自如的藝術創作：

Ctrl + Z：復原上一步動作 (Undo)
Ctrl + Y：重做下一步動作 (Redo)
Ctrl + S：儲存目前編輯中的標註
Delete：刪除目前在畫布上選取的標註
Esc：關閉編輯表單或關閉預覽氣泡
← / →：預覽模式下切換上一個/下一個標註

常見問題與分享訣竅 (Q&A)

問：學生家裡沒有安裝 Python，也沒有本軟體，能打開我匯出的 HTML 檔案嗎？

答：絕對可以！這正是本系統最大的特色。匯出的 .html 是 100% 獨立的單一靜態網頁，內含完整的樣式、腳本、底圖與語音引擎。任何人在 Windows、Mac、iPhone、Android 或 iPad 上，直接點兩下檔案或在瀏覽器開啟，即刻體驗全部互動功能！

問：在大螢幕電視、智慧黑板或觸控螢幕上教學時，有什麼最佳使用建議？

答：匯出的 HTML 頁面右上角配有「全螢幕模式（⛶）」按鈕，可直接隱藏瀏覽器標籤頁，享受無干擾的沉浸大螢幕展示。觸控螢幕支援直接手指點擊標註跳出氣泡，點擊右上角「🚀 自動巡航」還能像電視專題報導般，依序自動播放各點位的語音解說！

問：我能將做好的導覽圖放上學校網站或個人部落格嗎？

答：完全可以。您可以直接將該 .html 上傳至任何 Web 伺服器，或使用 <iframe src="導覽圖.html" width="100%" height="800"></iframe> 完美嵌入在任何網站、Google Sites、Moodle 或 Notion 頁面中。
