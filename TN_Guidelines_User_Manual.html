1. 系統簡介與核心精神

《臺南市國民中小學教師支持暨合理管教全攻略手冊》線上諮詢系統，是專為保障學生受教權益與教師教育專業尊嚴而打造的智慧化實務輔助工具。全系統以臺南市政府教育局民國 115 年 8 月初版之正式手冊為唯一依據，將 68 頁繁複的法規條文與 SOP 轉化為結構化的數位知識庫。

嚴格據實作答

系統嚴禁任意發明、推論或臆測。提問若超出本手冊記載之範圍，系統會誠實告知名稱與正式諮詢窗口，絕不勉強作答。

具體話術即時用

每個管教案例均提供老師現場可以直接照著說的具體溝通金句（對學生、對家長），協助降低言語對立與親師摩擦。

動態更新防過時

內建管理員中心可增修最新案例；同時支援使用者自訂 Gemini 模型名稱，確保系統歷久彌新不中斷。

2. 一般教師使用指南

2.1 如何進行情境問題查詢？

老師遭遇班級管教問題或親師溝通疑難時，可透過以下兩種方式進行查詢：

方法一：自然文字提問
在搜尋框輸入現場具體情境，例如：學生上課滑手機拒絕交出、課堂公開嗆老師、未交作業又不配合補交 或 家長在班級Line群組批評老師，按下 Enter 或點擊「查詢解答」。
方法二：點選熱門情境標籤
搜尋框下方精選了最常發生的管教情境標籤（如「未交作業」、「沉迷手機拒交」、「公開頂撞老師」、「同儕打架衝突」、「三級調和程序」、「心理諮商6小時補助」等），點擊任一標籤即可瞬間自動查詢。

2.2 查詢結果卡片的「七大關鍵維度」解讀

系統命中手冊案例後，會結構化呈現教育局建議的完整 SOP：

1. 核心處理原則

指引老師當下的整體應對心態與基本管教界線。

2. 先確認（釐清成因）

先釐清行為背後的動機（是注意力、家庭變故還是認知困難）。

3. 老師當下可以這樣做

提供第一時間的現場降溫處置步驟與操作示例。

4. 溝通話術金句（綠色泡泡）

提供現場可以直接照著說的具體語句（區分對學生與對家長）。

5. 若反覆發生後續處置

行為累犯時的個別會談約定、行為契約與支持措施。

6. 需要行政或專業協助

教務、學務、輔導處室的具體分工與外部專家轉介支援。

7. 教師應避免這樣做（紅線雷區）

重點提示容易衍生投訴、涉法或加劇衝突之違法或不當管教舉措，提醒老師避免觸犯。

2.3 雙核心運作機制：純內建檢索引擎 vs AI 智慧增強模式

系統支援雙軌檢索機制，老師可依自身需求彈性使用：

純內建精準檢索引擎（預設）
  • 完全免密鑰：開箱即用，不需輸入任何 API Key。
  • 極速反應：0.1 秒瞬時回傳手冊標準規範。
  • 嚴格對齊法規：字字句句出自官方手冊原文，未記載者誠實拒答。
AI 智慧增強模式（選填 API Key）
  • 多重情境整合：面對複合式管教問題時，由 AI 進行統整分析。
  • 嚴格恪遵手冊：後端已注入嚴格 System Instruction，限制 AI 只能以手冊數據為唯一真理，超出範圍絕不隨意瞎編。
  • 標示透明：回答卡片明確標記當前所調用之模型代碼。

2.4 進階設定：API Key 取得、自訂最新模型名稱、記憶與刪除

若希望啟用 AI 增強模式，請點擊網頁右上角的 「設定」（齒輪圖示）：

1. 免費取得 Gemini API Key

點擊彈窗內的「取得免費 API Key」連結，或前往 Google AI Studio。登入 Google 帳號後點擊「Create API Key」，複製 AIzaSy... 開頭的字串貼入設定框。輸入時可點擊眼睛圖示切換顯示/隱藏。

2. 自訂模型名稱 (避免模型過時失效)

預設模型為 gemini-3.5-flash-lite。系統提供快捷標籤（gemini-3.5-flash-lite、gemini-2.5-flash、gemini-1.5-pro），老師亦可根據 Google 官方可用模型清單 輸入 Google 最新發布之模型名稱。

3. 記憶與清除 (停用) 功能

• 儲存記憶：點擊「儲存記憶」後，資料將儲存於個人電腦或手機瀏覽器的 localStorage，下次開啟自動帶入，無須重複輸入。
• 清除 API Key (停用 AI)：若欲停用 AI 模式，點擊彈窗左下角紅色的「清除 API Key」按鈕，系統立即清空儲存並切回純內建檢索引擎。

2.5 首頁四大主題分頁導覽

除了主動搜尋，網頁下方提供了分頁標籤，方便全覽手冊核心精華：

20 大情境索引

涵蓋學習類、生活常規、人際與同儕、師生互動、心理健康、校園安全、突發高風險、親師溝通等 8 大類共 20 個案例卡片，點選任一項目即刻展開處置詳情。

陳情分流與三級調和

清楚界定「第一類法定通報事件（依法辦理，不得以調和替代）」與「第二類可啟動調和事件」之標準，並解說初級、二級、三級調和機制。

教師三大支持系統

詳細說明「行政支持（無罪推定、陪同說明）」、「心理支持（每年最高 6 小時心理諮商補助）」與「法律支持（法律諮詢補助方案）」。

附件法定表單說明（需至官方版下載）

介紹手冊附件 1（親師會談紀錄表）、附件 2（事件程序確認書）、附件 3（調和會議紀錄）的使用時機與流程。請注意：本程式系統並未提供空白表單檔案，請直接點擊連結至教育局官方手冊載點下載完整空白表單使用。

2.6 一鍵建立雲端 Google 文件 (.gdoc)

若老師或行政同仁需要將整本手冊留存在自己的 Google 雲端硬碟隨身閱讀或列印：

1. 點擊頂部導航列的 「雲端 .gdoc」 按鈕。

2. 系統後端將在 3 秒內自動於使用者的 Google Drive 根目錄建立一份排版完整的《臺南市國民中小學教師支持暨合理管教全攻略手冊》Google 文件。

3. 建立成功後將跳出確認視窗，點擊「確定」即可直接在新分頁開啟編輯與閱讀！

3. 管理員維護中心指南 (Admin Dashboard)

3.1 管理員身分驗證與登入

為維護系統資料公信力，增修案例與修改資料庫需具備管理員權限：

1. 點擊右上角的 「手冊管理」 按鈕（盾牌圖示）。

2. 於登入視窗中輸入管理員密碼（系統初始預設密碼為：admin888）。

3. 驗證通過後系統將記錄當前階段狀態，並自動彈出「手冊內容管理與維護中心」控制台。

3.2 案例清單管理：即時搜尋、編輯修訂與新增情境

進入管理中心之「案例清單管理」分頁：

🔍 即時搜尋過濾：在左上方輸入關鍵字（如「手機」或「作業」），表格將即時過濾顯示符合之案例。
✏️ 編輯既有案例：點擊該列的「編輯」按鈕，即可開啟全功能表單，修訂標題、原則、話術金句、雷區等。修改完成後點擊「儲存案例並生效」，系統首頁與查詢結果會立即同步生效。
➕ 新增全新案例：點擊右上方「新增自訂/新增案例」按鈕，填妥大類、章節、標題與處置內容後儲存，即可擴充全校知識庫。
🗑️ 刪除廢止案例：點擊該列的「刪除」按鈕，確認後即可自系統中移除過期或不適用之案例。

3.3 備份與同步：匯出 JSON、匯入 JSON 與恢復出廠預設值

切換至「備份與同步 (JSON)」分頁：

📥 匯出 JSON 備份 點擊「產生並複製 JSON」，系統將把整部手冊的所有分類、案例與話術結構打包為 JSON 字串並自動複製到剪貼簿，便於離線保存。
📤 匯入 JSON 覆蓋更新 若未來教育局主管機關發布批次修正版 JSON，管理員可直接貼入文字框，點擊「確認匯入並儲存」實現全校系統秒級整本更新。
🔄 一鍵恢復出廠預設值 若自訂編輯過程發生錯亂，可點擊「重置為預設」，系統將徹底抹除自訂修改，100% 恢復為民國 115 年 8 月初版之官方標準資料庫。

3.4 修改管理員密碼

在「變更管理密碼」分頁中，輸入目前舊密碼與兩次新密碼（至少 4 碼），點擊「確認更新密碼」，新密碼將安全保存於後端，日後請以新密碼登入。

3.5 底層雲端持久化儲存原理

系統修訂的所有資料均會自動持久化儲存在發布該 Web App 的 Google 帳號雲端硬碟根目錄下的 handbook_custom_data.json 檔案中：

  • 跨裝置即時同步：無論哪位老師透過手機或電腦查詢，系統皆優先讀取此份最新資料。
  • 與 .gdoc 自動同步：管理員修改完畢後，只要點選網頁頂端的「雲端 .gdoc」按鈕，系統生成的 Google 文件便會自動採用最新修訂的案例與文字！

4. 常見問題與疑難排解 (FAQ)

Q1：為什麼我查詢某些問題，系統會顯示「本手冊未記載此問題」？

答：這是系統遵循「嚴格據實回覆」之核心設計。本手冊專注於學生合理管教、陳情調和與教師權益支持。若問題超出此範疇（例如：成績評量細則、非管教之行政採購等），為保護師生權益，系統絕不隨意發明或臆測推論，並會明確提示洽詢校內權責處室或教育局主管科室。

Q2：輸入 API Key 後查詢出現錯誤訊息怎麼辦？

答：請開啟右上角「設定」，檢查以下項目：
1. 點擊眼睛圖示檢查 API Key 是否有空格或截斷。
2. 確認模型名稱是否有效（可點擊快捷按鈕切換回 gemini-3.5-flash-lite）。
3. 若暫時無網路金鑰額度，可點擊「清除 API Key (停用 AI)」，系統會立即無縫恢復為純內建精準檢索引擎。

Q3：如果忘記管理員密碼該如何處理？

答：專案部署發布者可直接登入 Google Apps Script 編輯器，於 Code.gs 內的 verifyAdmin 函式中查看或重設預設密碼，或清除 ScriptProperties 中的 ADMIN_PASSWORD 屬性即可還原為初始密碼 admin888。
