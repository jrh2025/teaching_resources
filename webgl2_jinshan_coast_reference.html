  • • 環狀航線自動運鏡（預設）：沿 0s–120s 樣條曲線依序飛越：金山國小 → 金包里老街 → 大鵬足湯公園/員潭溪 → 獅頭山光武坑道/燭台雙嶼 → 磺港漁港沙灘 → 中角灣國際衝浪基地 → 清水甘藷農地 → 返回金山國小。
