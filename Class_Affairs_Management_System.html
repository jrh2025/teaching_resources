第一步：建立專屬 Google 試算表

此試算表將作為您班級網站的雲端資料庫

  1. 點擊開啟 Google 試算表 (sheets.new) ↗ 建立一份全新空白表格。
  2. 將試算表左上角標題命名為「六年甲班 班級雲端事務中心_資料庫」（可依您的年級班別命名）。
  3. 從瀏覽器上方網址列複製網址，找出您的 試算表 ID：
    https://docs.google.com/spreadsheets/d/1Xgy6NWfWOwQTuE46aZzCpuBmD232x5lw5Lc0agBDuEY/edit

    （在 /d/ 與 /edit 之間的那串英數代碼即為您的試算表 ID）

  4. ✨ 貼心叮嚀：試算表內的工作表名稱與欄位保持空白即可！稍後系統首次啟動時，會自動幫您建置 7 大工作表與範例資料。
2

第二步：開啟 Apps Script 並貼上 Code.gs

建立後端邏輯與安全驗證端點

  1. 在剛建立的 Google 試算表上方選單，點選 「擴充功能」 ➔ 「Apps Script」。
  2. 將專案名稱（左上角「未命名專案」）點擊修改為「班級事務管理系統」。
  3. 在左側檔案清單中點選 Code.gs。
  4. 將編輯器中的預設代碼全選刪除（鍵盤按 Ctrl + A 再按 Delete）。
  5. 使用上方產生器的 「一鍵複製 Code.gs 代碼」，貼入編輯器中。
  6. 按下鍵盤 Ctrl + S（Mac 請按 Cmd + S）儲存專案。
3

第三步：建立前端網頁檔案 Index.html

建立家長與學生瀏覽的響應式美觀介面

  1. 在 Apps Script 編輯器左側「檔案」旁邊，點選 「+」號（新增檔案） ➔ 選擇「HTML」。
  2. 檔名直接輸入 Index 並按 Enter（系統會自動產生為 Index.html）。
  3. 將 Index.html 內的預設程式碼全部清空刪除。
  4. 使用上方產生器的 「一鍵複製 Index.html 代碼」，完整貼入 Index.html 中。
  5. 按下鍵盤 Ctrl + S 儲存。
4

第四步：發布部署為 Web App (關鍵步驟)

將程式碼正式發布為專屬班級網站網址

  1. 點擊 Apps Script 右上角藍色按鈕 「部署」 ➔ 選擇「新增部署作業」。
  2. 在彈出視窗左上角點選 齒輪圖示 ➔ 選擇「網頁應用程式 (Web App)」。
  3. 進行部署參數設定（請務必依下方設定）：
    說明：正式上線 v1.0
    執行身分：我 (您的 Google 帳號)
    誰可以存取：所有人 (Anyone)

    ⚠️「誰可以存取」務必選「所有人」，這樣家長與學生無需登入 Google 即可直接查看班級資訊！

  4. 點擊 「部署」 按鈕，系統會要求進行 Google 帳號授權：

    🔐 Google 授權驗證步驟（第一次部署才會出現）：

    1. 點擊「審查權限 (Review permissions)」並選擇您的 Google 帳號。

    2. 若出現「Google 尚未驗證這個應用程式」，請點擊左下角小字的 「進階 (Advanced)」。

    3. 點擊最下方 「前往『班級事務管理系統』(不安全)」。

    4. 點擊 「允許 (Allow)」 即可完成授權。

  5. 授權完成後，複製產生的 「網頁應用程式網址 (Web App URL)」，這就是您的班級專屬網址！
5

第五步：開啟網站、自動初始化與日常管理

開始體驗全功能班級雲端事務中心

1️⃣自動自癒與初始化

首次開啟網址時，系統會在背景自動於您的 Google 試算表中建立 7 大工作表並寫入預設範例資料，完全無需手動設定表格！

2️⃣安全教師登入與管理

點擊右上角「教師登入」，輸入您設定的密鑰（如 AdminTeacher2026），系統經由後端嚴格校驗通過後，即可發布聯絡簿、新增公告與編輯課表。

3️⃣布景與模組開關

教師登入後點擊「⚙️ 設定」，可挑選 6 大布景主題（海洋、森林、落日、薰衣草、櫻花、極簡），或勾選切換各模組對訪客的顯示狀態。

4️⃣分享給家長與學生

將網頁網址製成 QR Code 貼在聯絡簿黑板或印發給家長，家長隨時隨地用手機一掃即可查閱每日作業與班務公告！

💡常見問題與維護技巧 (FAQ)

Q1. 我日後修改了 Code.gs 或 Index.html，為什麼網頁沒有更新？ ▼

在 Google Apps Script 中，修改代碼儲存後，必須執行「更新部署」：

  1. 點擊右上角藍色 「部署」 ➔ 「管理部署作業」。
  2. 點擊右上角的 鉛筆圖示（編輯）。
  3. 在「版本」下拉選單中，務必選擇 「新版本 (New Version)」。
  4. 點擊右下角 「部署」 即可生效！
Q2. 家長和學生進入網站需要 Google 帳號登入嗎？ ▼

完全不需要！只要在第四步部署時，將「誰可以存取」設定為「所有人 (Anyone)」，任何人點開網址即可直接瀏覽，不需要登入任何帳號。

Q3. 訪客能隨意輸入密碼登入教師模式嗎？ ▼

絕不可能！最新版本採用後端 verifyTeacherLogin 進行嚴格的身分密鑰校驗。只有輸入與後端設定完全相符的管理密鑰才會被授予編輯權限，訪客任意輸入錯誤密碼將直接遭到後端阻擋並提示錯誤。
