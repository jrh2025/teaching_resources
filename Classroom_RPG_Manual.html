🎓 一、軟體設計理念與教育學理基礎

傳統課堂電競搶答軟體（如單純比手速的選擇題競賽）在教學現場常面臨兩大困境：其一是「快手壟斷、後段放棄」——閱讀較慢或需要思考時間的學生因搶不到分數而產生「習得性無助 (Learned Helplessness)」，最後淪為盲目亂猜；其二是「測驗與講解脫節」——老師無法在學生犯錯當下立即針對全班共同迷思進行視覺化介入。

本系統融合認知負荷理論 (Cognitive Load Theory)、差異化自主配速 (Self-Paced Mastery) 與合作學習理論 (Cooperative Learning)，首創「雙軌連動共鬥 (Dual-Track Co-op RPG)」架構：

🧭 第一軌：個人平板「差異化節點迷宮探索」

每位學生登入後皆生成獨立的 Top-Down 2D 節點迷宮（可設定 5 ~ 20 座守門怪聖殿與 2 ~ 5 間秘寶箱密室）。學生依照自己的思考節奏探索解題，不與他人比拼單題搶答手速，大幅降低測驗焦慮。

🐉 第二軌：教室大螢幕「全班世界魔王共鬥」

全班每位學生的正確作答（造成 100 傷，雙倍水 200 傷）與消耗 3 AP 發動的「🔥 集火攻擊」（500 點爆擊傷），皆透過 WebSocket 即時扣除大螢幕魔王總血量並觸發全班彈幕與跑馬燈，讓每位孩子的努力都成為團隊獲勝的關鍵！

🛡️ 無劇透鷹架與遊戲化容錯機制

作答前自動隱藏細項知識點標籤（僅顯示大單元名稱）杜絕標題洩題；答錯時明確標示 「❌ 答錯了：（所選選項）」 並呈現觀念詳解，重試時選項自動重洗牌。搭配「聖光護盾」、「消除卡 50/50」與「HP 歸零保留進度重生」，鼓勵學生從錯誤中學習。

❄️ 即時診斷矩陣與「一鍵全班凍結講解」

教師大螢幕右側即時統計全班各題答錯率並自動排序「熱點錯題」。老師點擊任一高錯誤率題目，即可一鍵鎖定全班平板畫面、暫停計時並同步投影該題詳解與放大圖表，達成「測驗 ➔ 診斷 ➔ 即時講解 ➔ 繼續闖關」的完整教學閉環。

📐 高挑戰度魔王血量平衡、答錯回血與「🛡️ 1 HP 不滅結界」過關標準：
• 動態或固定魔王血量：預設採用高挑戰公式 BossMaxHP = 在線學生人數 × 每人抽取題數 × 260（精準對應基礎傷害與 3 AP 集火期望傷害），教師亦可一鍵切換 「🟢標準 / 🟡困難(預設) / 🔴地獄史詩」、直接指定自訂固定總血量（如 15,000 HP），或於戰鬥中按大螢幕 「➕ 魔王補血 (+2000)」 即時延長戰線！
• 🧛 答錯題魔王闇能回血：學生答錯時，魔王會吸收錯誤能量自動回血（預設 +120 HP，教師可設 0~2000 HP）並觸發全班警示，有效杜絕亂猜。
• 🛡️ 教師自訂過關標準（1 HP 不滅結界）：教師可自訂全班最低通關進度 %（預設 75%）與全班最低答對率 %（預設 60%）；未達標前魔王最低會鎖血在 1 HP（啟動不滅結界），確保全班共同達標後才能完成最終斬殺！

📡 三、系統環境需求與純區網離線架構

🖥️ 教師端主機需求
  • 作業系統：Windows 10 / 11 (64-bit)（原始碼版亦支援 macOS / Linux）
  • 瀏覽器：Microsoft Edge 或 Google Chrome
  • 網路連線：與學生平板連上同一個教室 Wi-Fi 分享器（或由教師筆電開啟 Windows 內建「行動熱點」供學生平板連線，完全不需外網！）
📱 學生端平板 / 手機需求
  • 適用設備：iPad、Android 平板、Chromebook、手機或學生筆電
  • 零安裝負擔：免安裝任何 App、免註冊帳號
  • 連線方式：使用平板相機掃描教師大螢幕上的 QR Code，輸入「座號」與「姓名」即刻進入迷宮！

🚀 四、快速安裝與一鍵啟動指南

方式 A：免安裝綠色執行檔版（推薦直接分享給各科老師，免裝 Python）

  1. 前往下載 課堂互動RPG遊戲_教師分享完整包.zip（點此前往 Google 雲端硬碟下載） 並解壓縮至電腦任意位置（例如桌面）。
  2. 打開資料夾，直接雙擊 一鍵啟動_課堂互動RPG.bat（或直接雙擊 ClassroomRPG_HostServer.exe）。
  3. 系統會開啟一個黑色伺服器運作視窗（上課期間請保持此視窗開啟，勿關閉），並自動彈出瀏覽器進入 「教師大螢幕主控台 (http://127.0.0.1:8000/teacher)」。
  4. 首次啟動防火牆設定：若 Windows 彈出「Windows Defender 防火牆已封鎖此應用程式的部分功能」視窗，請務必同時勾選「私人網路」與「公用網路」，再點擊 「允許存取」。

方式 B：Python 原始碼環境啟動版（適合資訊教師或進階修改）

若電腦已安裝 Python 3.10+，可直接雙擊 Python原始碼與進階工具_SourceCode/start_server.bat，或於終端機執行：

pip install -r requirements.txt
python main.py

🖥️ 五、教師大螢幕主控台完整操作流程

  1. 課前設定（📦 題本・魔王・音樂設定）
    點擊大螢幕右上角 「📦 題本・魔王・音樂設定」：
    • 匯入題本 ZIP：可上傳自製的 .zip 題庫檔（分享包內附 範例題庫包_SamplePacks/rhetoric_elem_100.zip 可直接測試）。
    • 指定守關魔王：可選擇「🎲 隨機產生魔王」、指定 6 大內建魔王、輸入自訂魔王稱號，或上傳老師照片點擊「👑 上傳並化身教師魔王」。
    • 主題背景音樂 (BGM)：可即時切換 4 首內建合成音樂或上傳自訂 .mp3/.ogg/.wav 音樂檔。
    • 魔王挑戰難度、血量、答錯回血與過關標準：可一鍵套用 「🟢標準 / 🟡困難(預設) / 🔴地獄史詩」，或自訂每人每題魔王血量係數（預設 260）、魔王固定總血量、答錯時魔王回血量（預設 +120 HP），以及破除 1 HP 不滅結界的全班最低通關進度 %（預設 75%）與最低答對率 %（預設 60%）；戰鬥中亦可隨時按大螢幕 「➕ 魔王補血 (+2000)」！
    • 建立新課堂局次：選擇題本、設定課堂限時（1~60 分鐘）與每人隨機抽題守門怪數（5 ~ 20 題），點擊「✨ 建立新局並切換大螢幕」。
  2. 投影 QR Code 讓全班連線登入
    點擊左上角 「📱 QR Code」 放大顯示連線條碼。學生掃描登入後，大螢幕左側排行榜與右上角「🚀 開始遊戲 (N 人在線)」會即時顯示已連線學生，魔王總血量也會依人數自動平衡調整。
  3. 點擊「🚀 開始遊戲」與即時觀戰
    開戰後全班平板同步解鎖迷宮。每當學生答對題目或施放 3 AP 集火攻擊，大螢幕魔王會受擊震動並飄出傷害彈幕與黃金跑馬燈。
  4. 點擊熱點錯題發動「❄️ 一鍵全班凍結廣播講解」
    大螢幕右側「🩺 題本診斷矩陣」會即時將全班答錯率最高的題目排在最上方。老師點擊任一題目卡片，全班平板畫面會瞬間鎖定並同步顯示該題詳解（同時暫停倒數計時）；點擊附圖可 400% 放大平移講解。講解完畢點擊 「▶️ 解除凍結・恢復全班遊戲」 即可繼續闖關。
  5. 成功討伐魔王特效動畫與匯出 Excel 報表
    當魔王血量歸零時，自動播放全螢幕討伐勝利特效動畫（可隨時點擊 「🎬 重播成功討伐魔王特效動畫」 重複播放）。課後點擊 「📊 匯出 Excel 報表」 即可下載雙工作表 .xlsx 成績與錯題分析檔。

📱 六、學生平板／手機闖關操作說明

🚶 1. 四種迷宮移動方式（平板/手機皆順暢）
  • 一鍵導航（最推薦）：破關後直接點擊畫面頂部綠色 「🚶 前往下一關 (第 X 關)」 按鈕，勇者自動尋路走到下一關！
  • 點擊房間方塊：點擊地圖上已解鎖的房間即可自動行走。
  • 左下角虛擬十字鍵：點擊 ▲ ▼ ◀ ▶ 移動，按中央 ⚔️ 互動。
  • 手指拖曳滑動地圖：用手指按住地圖上下左右滑動檢視遠方關卡，按「🎯 視角置中」回到勇者身上。
⚔️ 2. 作答回饋、圖片放大與策略道具
  • 🔍 圖檔放大：點擊題目或詳解附圖即可開啟全螢幕放大鏡（支援縮放與手指拖曳平移）。
  • ✅/❌ 清晰正誤回饋：答對顯示綠字「✅ 答對了：...」，答錯顯示紅字「❌ 答錯了：...」與詳解說明。
  • 🎁 三大秘寶箱道具：✂️消除卡（刪去 2 個錯誤選項）、🛡️聖光護盾（自動抵擋一次答錯扣血）、🧪雙倍水（下一題雙倍 AP 與雙倍傷害）。
  • 🔥 集火攻擊：集滿 3 AP 可點擊頂部「🔥 集火攻擊」對大螢幕魔王轟出 500 點爆擊！

📦 七、如何自製與匯入專屬題本 (.zip) 教學

老師完全不需撰寫複雜程式！只需使用 Excel 填寫題目表（可直接開啟分享包內的 範例題庫包_SamplePacks/題庫範本_questions_template.xlsx 修改），搭配簡單的 manifest.json 與選填的圖片/音樂資料夾，壓縮成 .zip 即可匯入：

1. 題庫包 (.zip) 資料夾結構

my_pack.zip
├── manifest.json       (必填：設定題本名稱、學科、預設抽題數與時間)
├── questions.xlsx      (必填：標準 9 欄 Excel 題目表)
├── images/             (選填：存放題目附圖 .png / .jpg / .webp)
└── audio/              (選填：存放隨包主題音樂 .mp3 / .ogg / .wav)

2. Excel 題目表 (questions.xlsx) 9 大欄位規格

欄位名稱 必填 填寫說明與教學設計機制
A. 題號必填題目唯一編號（如 1, 2, 3...）。
B. 主題必填細項知識點名稱（作答前自動隱藏防洩題，僅於作答後詳解與教師診斷矩陣顯示）。
C. 題幹必填完整題目敘述文字。
D. 正確答案必填填入正確選項文字（系統發題時會自動與錯誤選項隨機洗牌打散順序！）。
E~G. 錯誤選項1~3必填填入 3 個誘答錯誤選項文字。
H. 詳解選填學生答錯時即時彈出之觀念解析，亦用於教師一鍵全班凍結講解。
I. 圖片檔名選填若題目有附圖，填入 images/ 下的檔名（如 q1.png），無附圖留空即可。

🛠️ 八、常見問題排解 (FAQ & 網路防火牆設定)

Q1：學生平板掃描 QR Code 後顯示「無法連上這個網站」怎麼辦？

  • 確認同一個 Wi-Fi 網段：請確保教師電腦與學生平板連接在同一個教室 Wi-Fi 下。若教室電腦使用校園有線網路、而平板連無線網路導致不同網段，最穩定的做法是開啟教師筆電的 Windows「行動熱點 (Mobile Hotspot)」讓學生平板連入，即使沒有外網也能 100% 順暢連線！
  • 允許 Windows 防火牆通過：首次啟動 ClassroomRPG_HostServer.exe 時，請於防火牆提示視窗勾選「私人網路」與「公用網路」並點擊「允許存取」。

Q2：學生不小心關閉瀏覽器或重新整理網頁，闖關進度會消失嗎？

  • 完全不會消失！ 只要重新掃描或重新整理網頁，甚至換一台平板輸入相同的「座號」與「姓名」，伺服器會立即從 SQLite 資料庫恢復該學生的所在房間、已破關卡、HP、AP 與持有道具。
