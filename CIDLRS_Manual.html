為什麼舊版一鍵複製會出現「Exception: HTML 內容格式錯誤」？

當手冊在瀏覽器中開啟時，若程式碼預覽區內直接含有 <title> 等標籤，部分瀏覽器會誤將程式碼當作真正的網頁標籤吞噬或修改。導致複製貼上至 Apps Script 時標籤遺失，造成 Apps Script 在啟動時拋出 Exception: HTML 內容格式錯誤：校園傳染病請假建議與衛教管理系統。
✨ 本手冊全面升級解決方案： 新增「📥 直接下載 Code.gs 檔案」按鈕（跳過剪貼簿與瀏覽器 DOM 渲染，0 遺漏純文字下載），同時手冊內部改採純文字隔離儲存技術，後端換用穩定的 HtmlService.createHtmlOutput()，保證一鍵複製與直接下載皆 100% 正確可用！

1

建立 Google 試算表並配置「關鍵共用權限」

本系統後端使用 Google 試算表作為資料庫儲存「查詢紀錄」與「疾病規則設定」。因為系統採用「以造訪者（老師本人）身分執行」以精準擷取每位老師的真實 Google 帳號，因此該試算表必須開放編輯權限。

操作步驟指南：

  1. 前往 sheets.new 建立一個全新的 Google 試算表，命名為例如：校園傳染病請假管理系統。
  2. 點選右上角藍色或綠色的 「共用」 按鈕。
  3. 在「一般存取權」區塊中：
    • 左側選擇：「知道連結的使用者」
    • 右側下拉選單務必改為：【編輯者】（若維持預設的檢視者，老師送出時將會報錯無寫入權限）。
  4. 點選 「完成」 儲存設定。
關鍵細節：如何複製試算表 ID？

請在瀏覽器網址列中，選取 /d/ 與 /edit 之間的一長串英數代碼：

https://docs.google.com/spreadsheets/d/14K5kh0t-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx/edit

※ 注意：切勿複製到 Apps Script 專案網址的 ID，兩者長度與開頭不同！

2

開啟 Apps Script 並填入試算表 ID

  1. 在剛建立的 Google 試算表頂端選單中，點選 「擴充功能」 ➜ 「Apps Script」。
  2. 進入 Apps Script 編輯器後，將左側 程式碼.gs 內原本預設的代碼全部反白清空。
  3. 您可以點擊手冊頂部綠色按鈕「下載 Code.gs 檔案」，用電腦記事本開啟並全選複製；或者在下方點擊「一鍵複製程式碼」，貼上至編輯器中。
  4. 找到程式碼第 22 行：
    // 請填入 Google 試算表 ID（網址中 /d/ 與 /edit 之間的一長串英數代碼）
    SPREADSHEET_ID: "替換成你自己的試算表ID",
    將引號內的字串替換為您在步驟一複製的試算表真實 ID。
  5. （選用）若要修改後台管理通行密碼，可直接修改第 19 行的 ADMIN_PIN: "您的密碼"（預設為 admin888）。
  6. 按下鍵盤 Ctrl + S（Mac: Cmd + S）儲存。

部署為 Web App（核心權限設定）

核心身分關鍵

這是確保系統能「100% 抓取到登入老師真實 Google 帳號且杜絕冒名」的最核心步驟。請嚴格按照以下參數挑選：

執行身分 (Execute as)
存取網頁應用程式的使用者
(User accessing the web app)
※ 讓後端能以該老師的 Google 帳號身分即時紀錄，杜絕偽造！
誰可以存取 (Who has access)
所有已登入 Google 帳戶的使用者
(Anyone with Google account 或機構成員)
※ 未登入 Google 者將直接被 Google 伺服器阻擋，保護校園系統安全。
具體畫面點擊路徑：
  1. 點選 Apps Script 編輯器右上角藍色按鈕：「部署」 ➜ 「新增部署作業」（若更新請點「管理部署作業」新增新版本）。
  2. 點擊左側「選取類型」的齒輪圖示，勾選 「網頁應用程式」。
  3. 「說明」欄可輸入：傳染病請假建議系統 V2.1 (防出錯版)。
  4. 將 「執行身分」 選為 「存取網頁應用程式的使用者」。
  5. 將 「誰可以存取」 選為 「所有已登入 Google 帳戶的使用者」。
  6. 點選右下角 「部署」。
  7. 複製系統產生的 「網頁應用程式網址 (Web App URL)」，此網址即為提供全校老師操作的入口！
4

首次開啟與 Google 權限審查通過流程

當任何老師第一次開啟 Web App 網址時，因為程式需要將資料寫入學校試算表，Google 官方會強制跳出標準的「需要授權」審查視窗。請指導老師依序點選以下四個步驟通過：

1
審查權限

畫面跳出「需要授權 (Authorization required)」，點擊藍色按鈕「審查權限」。

2
挑選帳號

選擇老師本人的 Google 帳號進行登入認證。

3
展開「進階」選項

畫面出現「Google 尚未驗證這個應用程式」，點選左下角灰色的「進階 (Advanced)」，接著點選展開的「前往『...』(不安全)」。

4
確認允許

捲動到底部，點擊「允許 (Allow)」，系統將自動完成初始化並進入系統！

故障排查矩陣 & 權限重設指南

解決 HTML 格式錯誤、SpreadsheetApp 權限不足與初次點選拒絕問題

排查核心
出現的錯誤現象 根本原因分析 立即解決方法
Exception: HTML 內容格式錯誤：校園傳染病... 舊版透過瀏覽器複製時遺失了標籤，或模板編譯引擎誤判。 直接使用本手冊頂端的「下載 Code.gs 檔案」功能，整檔覆蓋舊代碼即可永久解決！
錯誤：你沒有呼叫「SpreadsheetApp.openById」的權限 該帳號初次開啟時取消了授權，或試算表共用角色被設為「檢視者」。 前往 myaccount.google.com/connections 移除專案連結後重新整理授權，並確認試算表設為「編輯者」。
錯誤：請至 Code.gs 第 22 行填入正確試算表 ID 程式碼中的 SPREADSHEET_ID 仍為預設提醒文字，或複製到 Apps Script 專案 ID。 前往試算表複製網址 `/d/` 與 `/edit` 間的字串，貼回 Code.gs 第 22 行並發布「新版本」。
修改了程式碼，但線上網址完全沒變？ 在 Apps Script 僅按了「儲存」，未發布為「新版本」。 點選右上角「部署」➜「管理部署作業」➜ 點擊編輯鉛筆圖示 ➜ 版本選「新版本」➜ 點擊「部署」。

系統操作與管理維護指引

一般老師端操作流程
  1. 開啟 Web App 網址，系統頂端與表單內部會自動顯示當前已驗證之 Google 帳號。
  2. 填寫「學生學號」（例如：50109）與「學生姓名」（例如：林小安）。
  3. 從日曆元件挑選「確診日期」。
  4. 挑選疾病（流感、腸病毒、諾羅病毒、輪狀病毒等）。
  5. 點擊 「計算請假日期並寫入紀錄」。
  6. 右側即時展示請假起訖與返校日：
    • 一鍵複製純淨文字：自動整合衛教叮嚀並去除 Markdown 標記，直接貼至 LINE / 班級群組。
    • 下載 PDF 通知單：點擊「下載 PDF 通知單」，直出官方 A4 格式公文通知，含親師簽收聯。
衛生組 / 管理者後台操作流程
  1. 點選右上角 「後台管理」 並輸入管理密碼（預設 admin888）。
  2. 個別補印 PDF：在紀錄表格中每筆資料右側皆有「PDF」按鈕，可隨時補印歷史通知單。
  3. 批次勾選與刪除：可勾選各筆（或表頭「全選本頁」），點擊「批次刪除選取筆數」進行安全清除。
  4. 分頁與月份瀏覽：支援每頁 50 筆分頁切換；下拉選單可自動依確診月份快速過濾。
  5. 一鍵匯出 Excel：點擊「下載 Excel 檔」，直接將篩選後的資料轉為 Microsoft Excel (.xlsx) 存查。
  6. Markdown 衛教資訊維護：於疾病規則維護頁籤中直接利用 Markdown 排版（**粗體**、- 列表、> 警訊提示），儲存後全校即刻套用！
