單元 0·零基礎第一步

Google Apps Script 是什麼？如何開啟它？

Google Apps Script（簡稱 GAS）就像是 Google 為你準備的「24 小時免費雲端小助理」。它使用最熱門的 JavaScript 語法，不需要在電腦安裝任何軟體，只要有 Google 帳號就能直接在瀏覽器執行！

1 如何打開 Google Apps Script 編輯器？（兩種方式）

方式 A：從 Google 試算表開啟（最常用）

打開任何一份 Google 試算表 ➔ 點擊上方工具列的 「擴充功能」 ➔ 選擇 「Apps Script」。這會建立一個與此試算表直接綁定的腳本。

⭐ 推薦新手：最容易讀取與回寫試算表資料！
方式 B：直接獨立建立專案

直接在瀏覽器網址列輸入 script.new，或是前往 Google 雲端硬碟 ➔「新增」➔「更多」➔「Google Apps Script」。

適用情境：不附屬於特定檔案的獨立後端排程。

🛡️ 初學者必看：初次執行時跳出「警告危險」怎麼辦？（授權四部曲）

當你第一次在編輯器點擊「執行」時，Google 為了安全，會跳出「需要授權」與「Google 尚未驗證這個應用程式」的視窗。請別慌張！這是因為程式碼是你自己寫的，並非公開上架到 Google 商店的軟體。請依照以下 4 個步驟輕鬆放行：

步驟 1. 審查權限
點擊彈出視窗中的「審查權限」，並選擇登入你的 Google 帳號。
步驟 2. 點擊「進階」
看到「Google 尚未驗證」警告畫面時，點擊左下方小字的「進階」。
步驟 3. 前往專案
點擊下方最底部的「前往『未命名專案』（不安全）」連結。
步驟 4. 點擊「允許」
滾動至最下方按下「允許」，整個專案就完成安全授權了！
單元 1·手把手實戰

實戰一：試算表自動發送個人化郵件

從試算表中讀取「姓名」與「Email」，組合成個人化問候，並自動調用 Gmail 發送，最後將發送時間寫回試算表。

存放位置 Code.gs (GAS 預設腳本檔案) 
function sendWelcomeEmail() {
  // 1. 取得當前作用中的試算表與工作表
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  
  // 2. 讀取第二列的資料：A2 為姓名，B2 為 Email
  const name = sheet.getRange("A2").getValue();
  const email = sheet.getRange("B2").getValue();
  
  // 3. 設定信件主旨與內容 (反引號 `` 可直接嵌入變數 ${name})
  const subject = "歡迎加入！這是一封來自 GAS 的自動通知";
  const body = `親愛的 ${name} 您好：\n\n感謝您的參與！此信件由 Google Apps Script 雲端伺服器自動發送。`;
  
  // 4. 調用 Gmail 服務發送真實信件
  GmailApp.sendEmail(email, subject, body);
  
  // 5. 將發送結果回填至 C2 欄位，標註目前時間
  const timestamp = new Date().toLocaleTimeString();
  sheet.getRange("C2").setValue(`已發送 (${timestamp})`);
}
🔍程式碼逐行白話拆解（新手一定要看懂這 3 句）：
  • sheet.getRange("A2").getValue()：像拿鑷子夾取 A2 格子裡面的文字「王小明」。
  • GmailApp.sendEmail(收件者, 主旨, 內容)：Google 幫你準備好的發信函式，不用設定密碼直接發信。
  • sheet.getRange("C2").setValue(...)：把成果直接寫回 C2 儲存格，讓你在表格上一目了然。

單元 2·速度提升 50 倍

告別超時！二維陣列大批次處理 (getValues / setValues)

新手最常在 for 迴圈中不斷呼叫 setValue()，當資料有數百列時就會超過 6 分鐘的執行限制而當機。記住核心口訣：「用卡車整車載走，在記憶體算完，一次整車倒回去」！

❌ 逐筆操作（愚公移山模式）

每次迴圈都連線一次 Google 伺服器：
for (...) { sheet.getRange(i, 1).setValue("及格"); }
如果有 500 列資料，就要發送 500 次網路連線，極慢且極易報錯。

⚡ 批次操作（大卡車模式）

只連線 2 次！一次抓全部二維陣列，記憶體算完一次推回去：
const data = sheet.getRange(...).getValues();
sheet.getRange(...).setValues(results);

存放位置 Code.gs 
function batchProcessGrades() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const lastRow = sheet.getLastRow();
  if (lastRow <= 1) return; // 沒有資料就直接結束

  // 1. 【卡車裝車】：從第 2 列第 1 欄開始，一次性抓取全部 (lastRow - 1) 列與 2 欄資料
  const inputValues = sheet.getRange(2, 1, lastRow - 1, 2).getValues();
  
  // 2. 【記憶體運算】：準備一個二維陣列 [[結果1], [結果2], ...]
  const outputResults = [];
  for (let i = 0; i < inputValues.length; i++) {
    const score = inputValues[i][1]; // 取出該列的 B 欄分數
    outputResults.push([ score >= 60 ? "及格" : "不及格" ]);
  }
  
  // 3. 【卡車卸貨】：一次性寫入 C 欄 (第 3 欄)，長度完全對應運算筆數
  sheet.getRange(2, 3, outputResults.length, 1).setValues(outputResults);
}

單元 3·全自動定時排程

雲端鬧鐘：設定定時自動執行（電腦關機照樣跑）

程式寫完後，如果每天都要手動進去點「執行」，那就不是真正的自動化！利用 GAS 的「觸發條件（Triggers）」，你可以指定每天早上 8 點或每小時自動執行腳本。

⏰30 秒圖形化介面設定步驟（完全不需寫程式碼）：
  1. 在 Apps Script 編輯器左邊工具列，點選 「鬧鐘圖示（觸發條件）」。
  2. 點選右下角的藍色大按鈕 「+ 新增觸發條件」。
  3. 選擇要執行的功能：選定你要執行的函式名稱（例如 checkOverdueTasks）。
  4. 選取活動來源：切換為 「時間驅動」。
  5. 選取時間型觸發條件類型：可選「日計時器」（每天跑一次）或「小時預定時器」。
  6. 選取時段：例如「上午 8:00 到 9:00」，最後點擊「儲存」即可！
存放位置 Code.gs (定時巡檢逾期任務) 
// 此函式適合設定為每天早上 8 點定時觸發
function checkOverdueTasks() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const lastRow = sheet.getLastRow();
  if (lastRow <= 1) return;
  
  const today = new Date();
  const data = sheet.getRange(2, 1, lastRow - 1, 3).getValues();
  
  for (let i = 0; i < data.length; i++) {
    const dueDate = new Date(data[i][1]); // 假設 B 欄是到期日
    const status = data[i][2];            // 假設 C 欄是目前狀態
    
    // 若尚未完成且已過期，就在 D 欄標註警示
    if (status !== "已完成" && dueDate < today) {
      sheet.getRange(i + 2, 4).setValue("⚠️ 已逾期");
    }
  }
}
單元 4·試算表化身資料庫

將 GAS 發布為 Web App：建立 doGet 與 doPost API

只要在程式碼中寫好特定的函式名稱 doGet(e)（處理讀取請求）或 doPost(e)（處理寫入請求），你的試算表就能對全世界提供 API 服務！

存放位置 Code.gs (負責監聽外部網路連線) 
// 1. 處理外部瀏覽器網址傳來的 GET 請求 (例如 ?name=小明)
function doGet(e) {
  const name = e.parameter.name || "訪客";
  const result = {
    status: "success",
    message: `您好 ${name}，這是從 Google Apps Script 雲端回傳的 JSON 資料！`,
    timestamp: new Date().toISOString()
  };
  return ContentService.createTextOutput(JSON.stringify(result))
    .setMimeType(ContentService.MimeType.JSON);
}

// 2. 處理外部表單或 Webhook 送來的 POST 寫入請求
function doPost(e) {
  const lock = LockService.getScriptLock();
  lock.tryLock(10000); // 鎖定 10 秒防撞車

  try {
    const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    const data = JSON.parse(e.postData.contents); // 解析傳入的 JSON 內容
    
    // 自動在試算表最後一列追加資料
    sheet.appendRow([new Date().toLocaleTimeString(), data.name, data.note]);
    
    return ContentService.createTextOutput(JSON.stringify({ status: "success" }))
      .setMimeType(ContentService.MimeType.JSON);
  } finally {
    lock.releaseLock(); // 釋放鎖定
  }
}

單元 5·必經關卡

🚀 部署必勝手冊：將專案發布為公開 Web App

很多初學者寫好 doGet 或 LINE 機器人後發現「完全沒反應」，90% 都是因為「部署權限選錯」或「修改程式後忘記建立新版本」！請牢記以下部署秘訣。

步驟 1. 新增部署

點擊右上角藍色的 「部署」 ➔ 點選 「新增部署」 ➔ 點左邊的小齒輪 ➔ 選擇 「網頁應用程式」。

步驟 2. 關鍵權限設定 (極重要)

執行身分：選 「我」（用你的權限寫入表格）。
誰可以存取：務必改為 「任何人」（即使沒有登入 Google 也能呼叫，接 LINE 必選！）。

步驟 3. 取得正式網址

按下「部署」後，複製結尾為 /exec 的網址。這就是你的 API 或 LINE Webhook 網址！

⚠️新手最常犯的致命錯誤：修改程式碼後沒有更新部署！

當你部署完後，若又在 Code.gs 裡面修改了程式碼，原本的 Web App 網址依舊會執行「舊版本」！
每次修改代碼後，必須：點擊「部署」➔「管理部署作業」➔ 點擊鉛筆圖示 ➔ 版本選擇 「新版本」 ➔ 再次點擊「部署」，修改才會真正生效！

單元 7·資安防護

保護好你的密碼：使用 PropertiesService 保管 API Token

❌ 千萬不要把 LINE Token 或 OpenAI/Gemini 金鑰直接寫在程式碼中！如果試算表共用給同事，密鑰就會外洩。使用 GAS 的「指令碼屬性」，就像把金鑰放進加密保險箱一樣安全。

⚙️如何在編輯器中新增金鑰（圖形化介面）：

點擊編輯器左側的 「專案設定（齒輪圖示）」 ➔ 滾動到最下方找到 「指令碼屬性」 ➔ 點擊 「編輯指令碼屬性」 ➔「新增指令碼屬性」➔ 屬性名稱輸入 LINE_TOKEN，值貼上你的金鑰字串 ➔ 點擊儲存！

存放位置 Code.gs (如何用代碼讀取保險箱) 
function getSafeToken() {
  // 取得指令碼屬性儲存庫
  const properties = PropertiesService.getScriptProperties();
  
  // 依照設定的名稱讀取
  const token = properties.getProperty("LINE_TOKEN");
  
  if (!token) {
    throw new Error("找不到 LINE_TOKEN，請先至專案設定中配置！");
  }
  
  return token; // 安全取出金鑰供後續 API 調用
}

單元 8·實戰天花板

建立 LINE 雙向客服機器人 & Flex Message 精美圖文卡

結合 doPost(e) 接收 LINE 的 Webhook 訊息，比對試算表資料，並回傳圖文並茂的 Flex 卡片。以下是手機即時對話模擬器：

存放位置 Code.gs (處理 LINE 訊息回傳) 
function doPost(e) {
  const token = PropertiesService.getScriptProperties().getProperty("LINE_TOKEN");
  const event = JSON.parse(e.postData.contents).events[0];
  
  if (event && event.type === "message" && event.message.type === "text") {
    const userText = event.message.text.trim();
    const replyToken = event.replyToken;
    
    // 試算表關鍵字查表
    let reply = "您好！請輸入「營業時間」或「地址」查詢資訊。";
    if (userText.includes("營業時間")) reply = "本校服務時間為週一至週五 08:30 - 17:30。";
    if (userText.includes("地址")) reply = "校址位於：台北市信義區忠孝東路五段 100 號。";
    
    // 呼叫 LINE Reply API 回覆訊息
    UrlFetchApp.fetch("https://api.line.me/v2/bot/message/reply", {
      method: "post",
      headers: {
        "Content-Type": "application/json",
        "Authorization": "Bearer " + token
      },
      payload: JSON.stringify({
        replyToken: replyToken,
        messages: [{ type: "text", text: reply }]
      })
    });
  }
  return ContentService.createTextOutput("OK");
}

單元 9·最夯 AI 應用

在 GAS 中串接 Gemini API：打造「規則優先、AI 兜底」雙層客服

如果使用者輸入不在試算表裡的冷門問題，機器人該怎麼辦？傳統做法只能回答「聽不懂」，但最聰明的架構是：先查試算表，查無資料自動交給 Gemini AI 接手生成解答！

雙層智能防線工作流程
1. 查試算表 (免費又精準)

先搜尋常見問題清單，有答案就秒回，不消耗 AI 額度。

2. 查無結果 ➔ 觸發兜底

當試算表找不到時，自動帶入 System Instruction 呼叫 Gemini。

3. 溫暖回覆

AI 根據設定的角色語氣，生成客製化繁體中文回覆！

存放位置 Code.gs (Gemini REST API 串接函式) 
function callGeminiAPI(promptText) {
  const apiKey = PropertiesService.getScriptProperties().getProperty("GEMINI_API_KEY");
  const url = `https://generativelanguage.googleapis.com/v1beta/models/gemini-2.5-flash:generateContent?key=${apiKey}`;

  const payload = {
    system_instruction: {
      parts: [{ text: "你是一位親切專業的學校行政客服，請用繁體中文簡明扼要地回覆訪客。" }]
    },
    contents: [{ role: "user", parts: [{ text: promptText }] }]
  };

  const response = UrlFetchApp.fetch(url, {
    method: "post",
    headers: { "Content-Type": "application/json" },
    payload: JSON.stringify(payload),
    muteHttpExceptions: true
  });

  const resJson = JSON.parse(response.getContentText());
  return resJson.candidates[0].content.parts[0].text.trim();
}
