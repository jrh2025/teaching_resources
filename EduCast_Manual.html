📌 1. 系統簡介與核心定位

EduCast Pro 是一款專為中小學課堂互動教學、大學分組研討以及企業跨平台簡報展示量身打造的跨平台多端無線投屏與導播系統。

傳統教學與會議投影方案常受限於專用硬體發射器（易故障遺失）、要求安裝專用 App、無法跨平台操作或依賴外網雲端伺服器導致延遲與資安隱患。 EduCast Pro 採用革命性的「純區域網路極速直連 + 零安裝 Web/Native 雙模架構」：學生與與會者無需安裝任何 App，只需用相機掃描 QR Code，即可在 1 秒內將白板筆跡、相機實物、課本作業、照片或系統桌面即時投屏至大螢幕！

🌟 零安裝、極致低延遲、免外網連線： 完全運行於教室或會議室本地區域網路 (Wi-Fi/LAN)，即使在無外網的隔離封閉環境中也能 100% 順暢穩定運行。

💡 2. 核心設計理念 (Design Philosophy)

  • 零摩擦力接入 (Zero-Friction Adoption)：學生免裝 App、免註冊登入、拿起 iPad/Android 手機掃描 QR Code 即刻上台。
  • 本地優先與絕對隱私保護 (Local-First & Air-Gapped Security)：所有影音、手寫與作業資料 100% 留在校園/企業內網，絕不流出至公有雲。
  • 影音聲畫同步技術 (Sync Audio-Visual Streaming)：突破一般網頁投屏無法同步聲音的障礙，手寫、影片、相機直播均具備清晰聲音同步傳輸。
  • 智慧長寬比自適應與黑邊消除 (Intelligent Aspect-Ratio Adaptation)：手機直放與橫放翻轉時自動偵測裁切上下/左右純黑邊，大螢幕永遠呈現 1:1 滿版正確比例。
  • 大螢幕滑鼠與鍵盤雙向反向控制 (Bi-Directional Reverse Control)：老師可直接用滑鼠在大螢幕上批改學生白板，或按 Enter 反向鍵盤打字輸入至學生手機。
  • 教學認知卸載與課堂秩序掌控 (Pedagogical Orchestration)：一鍵全班鎖屏、多宮格自由指定學生畫面、聚光燈與滿版大螢幕即時廣播。

📱 5. 學生端五大投屏模式詳解

1

✏️ 手寫白板投屏（預設）

具備白板格線紙、四色白板筆、橡皮擦與打字功能。針對觸控筆優化防手掌誤觸，筆跡即時同步大螢幕，並支援老師電腦滑鼠反向同步批註。

2

📸 拍作業 / 截圖投屏

直接呼叫手機相機拍攝課本、試卷或筆記，1:1 原比例高解析度呈現，徹底杜絕畫面被拉長或壓縮。

3

📹 實物鏡頭連續直播 (HTTPS)

提供加密安全通道，支援 30fps 即時攝影機串流與麥克風聲音同步，可自由切換前/後鏡頭，適合實驗過程與立體教具展示。

4

🖥️ 全螢幕系統級鏡像

支援透過 ScreenStream (RTSP 8554 有聲 / MJPEG 8080) 串流、影片直接投屏或 Windows 原生無線投影 (Miracast)，在手機切換至任何第三方 App 時均持續穩定同步大螢幕與聲音！

5

🎬 影片投屏（影音聲畫同步）

選取相簿錄製的專題短片，大螢幕以硬體加速流暢播放，聲音由教室音響同步播放。

❓ 7. 常見問題與疑難排解 (FAQ)

Q1：學生手機掃描 QR Code 顯示無法連線至網頁？
• 檢查 Wi-Fi：請確認學生手機與教師電腦連在同一個 Wi-Fi 分享器下。
• 網卡 IP 切換：若電腦同時連接了有線網路與無線網路，請在大螢幕歡迎看板的「目前學生掃碼連線網址」下拉切換為真實的 Wi-Fi 網卡 IP。
• 防火牆設定：首次啟動請允許 Windows 防火牆通過專用網路（連接埠 3000、3443）。
Q2：使用實物鏡頭直播 (HTTPS) 出現安全性提示？
因系統採用純區網自簽 SSL 憑證以杜絕外部聯網，學生手機點擊「進階」➔「繼續前往」即可（只需點擊一次永久有效）；若學生不想看到提示，亦可在彈窗點選「拍照投屏」，完全在 HTTP 模式下零警告運行。
Q3：廣播畫面至學生平板時，如何結束廣播？
點擊左下角「⏹️ 結束廣播」圖示按鈕，系統會立即向全班學生設備發送結束指令，全班平板圖層自動關閉並 100% 恢復原本的手寫與投屏操作。學生亦可隨時在自己的平板右上角點擊「✕ 返回白板」繼續作答。
