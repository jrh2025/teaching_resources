《StackCity RT（像素疊界）》

結合 CityRT 即時微縮城市互動體驗 與 Sprite-Stacking（精靈堆疊）偽 3D 像素體素造物技術 的單一執行檔創意沙盒與互動遊戲導演系統。

⬇️ 下載 stackcity-rt.exe（Windows 免安裝約 12.9 MB） 📖 立即查看手把手教學

1. 設計理念（Design Philosophy）

🎨 人人皆可造物 3D 世界

不需學習複雜的專業 3D 軟體，透過中文語意提示、68 種內建原型、3D 積木細調、四視圖雕刻或 AI 生成，由純 Rust 體素引擎瞬間烘焙出 360° 立體像素物件。

🎮 從靜態搭建走向動態闖關

不只是放置建築擺拍。您能設定三軸尺寸、巡航路徑、漫遊圍欄、乘載附掛與定時事件，更可設計推理抓兇、積分賽、尋寶與選擇題，製作成完整過關遊戲。

📦 單檔自包含與零依賴分享

主程式即單一 .exe；每個世界封裝於單一 .stackworld.db；更可一鍵匯出離線可玩的純玩家版 .html 網頁，傳給任何人皆零門檻開啟。

2. 核心軟體特色

✨ 純 Rust Sprite-Stacking 造物工坊

  • 內建 6 大類 68 種原型（建築、人物、動物、植物、載具、家具），支援積雪／發光／色系語意修飾。
  • 3D 積木細部編輯器：可微調物件名稱、畫布 W×D×H、位置 X/Y/Z、長寬高、半徑、10 種材質、夜間發光與 X 軸鏡像。
  • 純記憶體預覽保護：調整草稿時僅在記憶體烘焙轉盤預覽，未確認儲存前絕不寫入個人資產庫。
  • 支援四視圖 PNG 外殼雕刻與 .zip / blueprint.json / slices.png 匯入。

🤖 AI 藍圖建模（Gemma 4 / Gemini / OpenAI）

  • 原生支援 Google Gemma 4（gemma-4-31b-it、gemma-4-26b-a4b-it）、Google Gemini（2.5 / 3 主流型號）與 OpenAI 相容端點。
  • 模型名稱可自由編輯不過時，提供 「🔍 查可用模型」 即時查詢金鑰可用型號與 404 自動排錯建議。
  • 支援依供應商本機 記憶與移除 API Key，並依介面語系引導 AI 生成對應語言物件標題。

🌆 WebGL2 3D 微縮渲染與貼近常理物理

  • 每層精靈切片採三疊微厚度重疊，支援硬體 Z-Buffer、normals.png 法線三階光影與地面動態陰影。
  • 24 小時日夜光影、晴雨雪天氣（屋頂自動積雪）、夜晚自動點亮 emissive.png 燈光。
  • 陸地角色／動物／玩家自動阻擋落入無橋深水（支援踏上橋面通行）並附 2D 旋轉 OBB 建築碰撞避障。

🏆 活體事件導演、專屬玩家與任務系統

  • 可設定玩家專屬角色（Avatar）、自由換裝、上帝視角 WASD 移動與 CityRT 街道漫步視角。
  • 支援三軸獨立縮放（X/Y/Z）、巡航路徑、漫遊圈、乘載附掛與解除附掛。
  • 支援 6 種 NPC／物件考驗（線索、選擇題、搶劫、支援、寶藏、嫌疑犯）與 5 種過關目標，過關即觸發慶賀畫面。
  • 內建 5 種截然不同的多軌程序化配樂＋自訂音樂封裝，及繁中／English／日本語三語系即時切換。

4. 系統安裝、啟動與介面導覽

4.1 三種啟動方式

  1. Windows 免安裝直接執行：下載 stackcity-rt.exe 放進任意可寫入的資料夾，直接雙擊啟動（預設網址 http://127.0.0.1:8788）。
  2. 開放同區網（教室／家用 Wi-Fi）多人連線： 
    .\stackcity-rt.exe --host 0.0.0.0 --port 8788 --data-dir .\worlds
    同網段其他裝置在瀏覽器輸入 http://<主機區網IP>:8788 即可共同遊玩。
  3. macOS / Linux 原始碼編譯：安裝 Rust 工具鏈後執行 cargo test && cargo build --release 即可編譯該平台單檔執行檔。
Windows SmartScreen 提醒：因個人開源程式未購買商業數位簽章，初次執行時若出現「Windows 已保護您的電腦」，點選「其他資訊 → 仍要執行」即可正常運作。

4.2 主畫面四大區塊

  • 頂部導覽列：世界切換與 ✏️ 重新命名、新建與擴展世界、編輯／參觀模式切換、24h 時光與天氣、玩家角色、街道漫步、音樂、重置／刪除、快照、分享、面板收合、多語系切換與全螢幕。
  • 左側工具與資產庫（可收合）：9 大編輯工具、生態筆刷子選項，以及可依分類篩選、點擊投放或按卡片右上角 ✕ 直接從本世界移除的資產網格。
  • 中央 3D 畫布與任務 HUD：WebGL2 立體視口、視角重設按鈕、街道漫步橫幅與右側浮動 任務追蹤面板（顯示分數、血量、護盾、線索筆記與重置按鈕）。
  • 右側屬性導演面板（可收合）：🎛️ 屬性（含三軸縮放、解除附掛與物件考驗設定）、〰️ 路徑、🎬 事件、🏆 任務。

6. 手把手使用教學

步驟 1：建立與調整世界

點「＋ 新建世界」從 12 種主題起手；隨時可按世界選單旁的 ✏️ 改名，或點「🗺️ 擴展場景」向東南西北四側擴張格數（既有建築與路徑自動保持相對位置遷移）。

步驟 2：造物與精細修圖

在「✨ 造物工坊」快速生成或進「🧱 3D 積木藍圖」調位置、長寬高與材質。未確認前僅在記憶體預覽；輸入目標名稱後點「💾 確認儲存至資產庫」才正式寫入。

步驟 3：安排活體行為與任務

選取場上 NPC 或道具，在右欄指派路徑、漫遊圈、事件規則，並在「🎯 任務互動與考驗設定」寫好對話、選擇題或搶劫／尋寶條件，再到「🏆 任務」分頁設定過關條件。

步驟 4：測試遊玩與分享

切至「👁️ 訪客參觀中」或進入「🚶 街道漫步」實測通關；確認滿意後按下「🔄 重置 → 清除遊玩進度」歸零測試成績，即可點「🤝 分享」傳給朋友。

10. 常見問題 FAQ

Q1：分享程式或遊戲給朋友，對方電腦需要安裝什麼嗎？

不需要安裝 Rust、Python、Node.js 或 SQLite。傳送 stackcity-rt.exe 給 Windows 朋友即可直接執行；若只要讓對方純玩關卡，匯出「單純遊戲網頁檔（.html）」後，對方在任何作業系統用瀏覽器雙擊即可離線遊玩。

Q2：使用 AI 藍圖遇到 404 模型錯誤怎麼辦？

請將供應商切為「Google Gemma 4（開放模型）」或「Google Gemini」，先填入 API Key 後按一下「🔍 查可用模型」，系統會自動向官方查詢您的金鑰實際支援的模型名稱並列出快捷晶片供點選。

Q3：為什麼我在 3D 積木分頁調整數值，個人資產庫沒有馬上多出新檔案？

為避免反覆微調尺寸產生大量半成品，所有即時預覽都在記憶體中完成；請在確認物件名稱與外型滿意後，點擊「💾 確認儲存至資產庫」或「💾 覆寫儲存原物件」，才會真正寫入資產庫。

Q4：如何替換或切換介面語言？海外朋友看得到英文介面嗎？

系統會自動偵測對方瀏覽器語系（英文系統自動顯示 English、日文系統自動顯示日本語），主程式與匯出的獨立 .html 頂部皆附有語系選單（🌐），隨時可於繁體中文、English 與日本語間無損切換。
