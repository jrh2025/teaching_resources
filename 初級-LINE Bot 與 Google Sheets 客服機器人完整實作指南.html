🧠 運作原理與系統資訊架構

本系統利用 Google Apps Script (GAS) 作為中繼伺服器（Web App），整合 LINE Messaging API 與 Google Sheets 試算表。當訪客在 LINE 發送訊息時，LINE 伺服器會透過 Webhook 將 HTTP POST 請求推播至 GAS，由 GAS 檢索試算表內的關鍵字，並即時透過 Reply API 回傳解答。

🚀 五步驟從零打造智慧客服 (超詳細實作範例版)

本嚮導提供精準直覺的步驟指示與現成範例資料。勾選完成事項，系統會即時統計進度；點選範例按鈕可直接複製到 Google Sheets 中使用！

建置驗收進度： 0 / 5
Google 端

1. 打開 Google Sheets 快速新增頁面，將檔案命名為 LINE FAQ 資料庫。

2. 最關鍵設定：將試算表底部的工作表分頁標籤（預設為「工作表1」）重新命名為 FAQ（大小寫需完全相符）。

📋 試算表範本資料 (包含標題列與 5 筆預設問答)
• 欄位 A (關鍵字)：訪客提問會觸發的字詞（如：地址、營業時間、電話、費用、預約）
• 欄位 B (回覆內容)：機器人回傳的文字訊息（支援換行排版）
• 欄位 C (比對模式)：contains (模糊包含) 或 exact (完全相符)

3. 點選頂部選單 **擴充功能 > Apps Script**，按 Ctrl + A 全選並刪除預設的 myFunction。

4. 切換到本工具的「💻 腳本生成」頁籤，點選「一鍵複製程式碼」並貼入 GAS 編輯器。

5. 點擊右上角藍色 **部署 > 新增部署**：

  • 點擊齒輪選擇 網頁應用程式 (Web app)
  • 說明：填寫 v1.0
  • 執行身分：選擇 我 (您的 Google 帳號)
  • 誰可以存取：務必選擇「所有人 (Anyone)」 (若選「僅限自己」，LINE 伺服器會被擋下)

6. 點擊「部署」，完成帳號安全性授權後，複製產生的 Web app URL 網址 備用。

LINE 帳號

1. 前往 LINE Official Account Manager 使用個人 LINE 帳號登入。

2. 點選右上角 **「建立官方帳號」**：

• 帳號名稱範例：JRH智慧客服No.01 或您的品牌店名
• 電子郵件：您的常用聯絡信箱
• 業種：選擇最相近項目（例如：服務/零售/其他）

3. 建立完成後進入後台，點選右上角的 **設定 (齒輪圖示)** > 左側選單選擇 **Messaging API**。

4. 點擊畫面中央綠色的 **「啟用 Messaging API」** 按鈕：

  • Provider (服務提供者)：若首次使用，請點選「建立新的提供者」，輸入如 JRH-Lab 或英文縮寫。
  • 隱私權政策與服務條款可直接略過，點擊「確定」。

5. 啟用成功後，點擊該頁面下方的超連結前往 LINE Developers Console。

高頻地雷
1️⃣ 後台 A：LINE Official Account Manager (`manager.line.biz`)
進入 **設定 > 回應設定**：
• 聊天 (Chat)：切換為 關閉 (OFF)！
• Webhook：務必維持 開啟 (ON)！
※ 原因：關閉聊天能杜絕官方預設罐頭訊息（「無法個別回覆...」）阻斷 GAS 的回答！
2️⃣ 後台 B：LINE Developers Console (`developers.line.biz`)
點進剛才建立的 Channel > 切換至 **Messaging API** 頁籤：
• Webhook URL：點擊「Edit」貼上第一步取得的 GAS 網址（結尾必須為 /exec），點「Update」。
• Use webhook：開關切換為 開啟 (綠色 ON)。
• Channel access token：捲動至最底部，找到 Channel access token (long-lived)，點擊黑色的 Issue 按鈕發行長串權杖，點擊複製圖示。
版本快照

1. 回到 Google Apps Script 編輯器，找到最上方的常數：

const CHANNEL_ACCESS_TOKEN = '貼上從LINE Developers複製的超長Token';

2. 按下 Ctrl + S 儲存專案。

3. 核心防呆步驟 (發布新版本)：

  • 點選右上角 **部署 > 管理部署**。
  • 點擊右上角的 **鉛筆圖示 (編輯)**。
  • 在「版本」下拉選單中，切換為 **新版本 (New version)**。
  • 點擊右下角 **部署** 按鈕。

(小知識：GAS 若只按儲存，對外的 Webhook 仍會執行舊版本。唯有「發布新版本」才能套用新 Token)

成功驗收

1. 忽略 Verify 報錯：若在 LINE Developers 點擊 Verify 彈出 302 Found 提示，直接點 OK 關閉（此為 Google 正常轉址機制）。

2. 打開手機或電腦版 LINE，加入您的官方帳號，發送測試詞句：

測試模糊比對：
輸入「請問你們地址在哪裡？」
➔ 機器人命中「地址」並回傳完整地址！
測試精確比對：
輸入「電話」
➔ 機器人命中並回傳客服專線！

3. 日後如需更新問答，直接在 Google Sheets 新增列或修改文字即可即時生效，完全不需再次修改程式碼！

⚠️ 實務踩坑大解密與診斷室

串接 LINE Bot 與 GAS 時最常見的障礙通常來自權限機制、302 轉址誤解或快照版本問題。請點選下方按鈕快速篩選常見症狀與解決方案：

地雷一 manager.line.biz

🤖 LINE 一直回覆「本帳號無法個別回覆」

「感謝您的訊息！很抱歉，本帳號無法個別回覆用戶的訊息...」
🔍 底層原因分析：

這是 LINE 官方帳號管理後台的預設「自動回應訊息」在作祟。在「回應設定」中若開啟了「回應時間」或未關閉手動聊天，非營業時間會自動發送罐頭訊息覆蓋 Webhook。

✅ 終極解法：

登入 LINE Official Account Manager > 設定 > 回應設定：將最上方的 「聊天 (Chat)」切換為關閉 (OFF)，只保留 Webhook (ON)。

地雷二 developers.line.biz

🔄 Verify 按鈕跳出 Error: 302 Found

The webhook returned an HTTP status code other than 200.(302 Found)
🔍 底層原因分析：

這是 Google Apps Script 的架構天性！GAS 接受 POST 請求時必先發送一次 HTTP 302 重導向。LINE 網頁端的 Verify 測試工具不支援追蹤 302 因而報錯，但 LINE 正式訊息推播伺服器完全支援 302 轉址！

✅ 終極解法：

直接點擊 OK 忽略該錯誤！只要 Use webhook 是開啟（綠色 ON），直接用手機傳送真實訊息測試即可。

地雷三 script.google.com

🔑 GAS 顯示「已完成」，但 LINE 已讀不回

doPost 執行 1.6 秒 (已完成) -> 手機無任何回覆訊息
🔍 底層原因分析：

在 LINE Developers 頁面最下方的 Channel access token 依然顯示黑色的 **Issue** 按鈕，代表根本未發行 Token，呼叫 LINE Reply API 時遭到 HTTP 401 拒絕。

✅ 終極解法：

點擊黑色 Issue 按鈕，複製生成的超長 Token 貼回 GAS 的 CHANNEL_ACCESS_TOKEN，並發布新版本。

地雷四 GAS Versioning

📌 修改了 GAS 程式碼或 Token，完全沒反應

按了「儲存 (Ctrl+S)」-> 機器人依然執行舊版本
🔍 底層原因分析：

Google Apps Script 的快照機制：單純按「儲存」只會改變線上編輯器的草稿。外部 Webhook 網址依然停留在上次發布的舊版本快照。

✅ 終極解法：

修改後點選 **部署 > 管理部署 > 鉛筆圖示 (編輯)** > 版本切換為 **新版本 (New version)** > 點擊 **部署**。

地雷五 (高頻語法錯誤) [GLOBAL] SyntaxError

💥 SyntaxError: Unexpected token '}' 或 Unexpected end of input

[GLOBAL] SyntaxError: Unexpected token '}' / Unexpected end of input
🔍 底層原因分析：
  • Unexpected end of input (最常見)：直譯器讀到了腳本結尾，卻發現仍有括號 } 或字串引號 ' 尚未閉合。通常是因為在貼上 Token 時誤刪了結尾的單引號 '，導致整份程式碼全被當成未結束的字串。
  • Unexpected token '}'：GAS 預設有 function myFunction() {}，貼上新程式碼時若殘留了多餘的孤立 } 所導致。
  • 專案多餘檔案干擾：Apps Script 左側若有其他未命名的空 .gs 檔案，會在全域編譯時一同被載入並引發錯誤。
✅ 終極解法：

1. 檢查 GAS 左側「檔案」清單，刪除所有多餘或空白的 .gs 測試檔，僅保留主要檔案。

2. 在編輯器內按 Ctrl + A 全選並按 Delete 完全清空。

3. 切換至本網頁「腳本生成」頁籤，貼上 Token 後點擊「📋 一鍵複製程式碼」並貼回 GAS。

4. 在 GAS 上方選取 testConnection 函式點擊「執行」，先進行自我環境與語法檢驗！
