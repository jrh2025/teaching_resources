大北門三維地景重構系統 — 操作說明與互動指南

支援無人機自動導覽、自由飛行探索、即時光學調參與高品質超取樣渲染

✈️ 1. 雙模式無人機運鏡控制

  • • 史詩航線自動運鏡（預設）：沿 0s–120s 三維樣條曲線由內陸西港曾文溪（高度 15m）推進至七股頂頭額沙洲（高度 180m），自動運鏡期間仍可按住滑鼠左鍵拖曳 360° 環視四周。
  • • 自由飛行模式（Free Flight）：點擊頂部「史詩航線運鏡」按鈕或直接按鍵盤 W A S D / 方向鍵 即可接管無人機自由探索。
  • • 垂直升降與加速：自由飛行時按 E（上升）、Q（下降）調整高度，按住 Shift 可開啟 2.3 倍高速巡航。

🗺️ 2. 五區快速跳轉與 2D 雷達瞬移

  • • 五大代表地景一鍵跳轉：點擊底部 ① 西港曾文溪、② 佳里平原、③ 將軍魚塭、④ 北門鹽田、⑤ 七股沙洲 按鈕（或按數字鍵 1～5）立即切換。
  • • 2D 符號距離場雷達瞬移：點擊左上角「2D 符號距離場與宏觀分區雷達」小地圖上的任意海陸位置，無人機將立即傳送至該世界座標（跨度 -2km 外海至 24km 內陸）。
  • • 時間軸拖曳：隨時拉動底部時間軸滑桿檢視 0s–120s 任意時刻的地貌過渡。

🌅 3. 光學調參與 SPP=16 超取樣渲染

  • • 嘉南夕色光影實驗：於右側面板調整太陽仰角（1.5°～45°）、太陽方位角與大氣渾濁度（Mie 散射），觀察低角度斜陽在 35cm 田埂、圓錐鹽堆與沙丘稜線投射的修長陰影。
  • • SPP 靜態高品質渲染：點擊頂部「SPP 靜態渲染」，系統將暫停動畫並透過 Halton 次像素抖動連續累積 16 次取樣（16x Supersampling），消除所有邊緣鋸齒與噪訊，完成後即自動停止 GPU 運算。

⚡ 4. 流暢度最佳化、全螢幕與自然聲景

  • • 全螢幕沉浸檢視：點擊右上角「⛶ 全螢幕」（或按 F 鍵）展開全螢幕，搭配 H 鍵隱藏控制面板即可獲得純淨航拍畫面。
  • • GPU 流暢度調節：若使用筆電內顯，可點擊頂部綠色「⚡ 極速省電」或調降右側「畫面解析度與銳利度」；若使用獨立顯卡，可拉升至 1.25x 體驗極致銳利細節。
  • • 四層動態自然聲景：點擊「🔇 聲景」（或按 M 鍵）開啟海浪潮汐、甜根子草微風與大北門濕地水鳥鳴叫。
