ProPDF Studio 完整使用操作指南

詳細拆解六大核心工作流程，協助您在數分鐘內熟悉所有操作細節與進階技巧。

01

介面佈局與檔案管理入門

ProPDF Studio 採用類似 Adobe Acrobat 的高效率現代化三段式架構：

1. 頂部精簡工具列

左側包含 ➕ 新建、📂 開啟 與 ↩️ 上一步 / ↪️ 下一步；中間為四大閱讀模式；右側包含自動暫存藥丸、📦 存專案、👁️ 預覽、💾 另存 PDF、📝 轉存 Word 與 📊 轉存 Excel。

2. 模組分頁列 (Nav Bar)

一鍵在「✏️ 編輯文字與圖片」、「🖍️ 註解與簽名」、「📑 整理頁面」、「🔍 掃描轉文字 (OCR)」、「🛡️ 密碼與塗黑」、「🔄 轉檔批次」之間平滑切換，下方次級工具列自動連動。

3. 畫布編輯與側欄

左側抽屜可快速檢視頁面縮圖、目錄大綱與註解列表；中間畫布呈現高解析 1:1 標準 A4 紙張；右側為即時屬性控制面板。

💡 專家提示（多元匯出格式指南）：
• 📦 存專案 (.propdf)：保留所有向量物件、字型樣式、表單欄位與圖層，供日後 100% 重新載入繼續編輯。
• 💾 另存 PDF：產生符合國際標準的高解析度 PDF 檔案，供正式列印、送簽或跨平台檢視。
• 📝 轉存 Word (.doc)：完整保留所有頁面的標題大小、文字段落與行距，直接可用 Microsoft Word 開啟編輯。
• 📊 轉存 Excel (.csv)：將文件中的條文段落、表格數據與互動表單填寫內容匯出為 CSV 試算表（UTF-8 繁中防亂碼）。
02

文字編輯、圖片排版與正則搜尋取代

  1. 編輯現有文字：雙擊畫布上的任意文字段落，游標將進入編輯狀態。此時可直接輸入文字、修改內容。
  2. 修改樣式：選中文字區塊後，可在次級工具列或右側屬性欄自訂字體（思源黑體、標楷體、Arial 等）、字級大小、文字色彩、粗體/斜體、行距與對齊方式。
  3. 新增文字方塊：點擊工具列上的「➕ 新增文字」，滑鼠在畫布上點擊即可放置新文字。
  4. 插入圖片：點擊「🖼️ 插入圖片」選擇本機圖檔（PNG / JPG / WebP），插入後可自由拖曳調整位置，或拉動邊角控制點等比縮放。
  5. 全文搜尋與取代（Ctrl+F）：點擊頂部的放大鏡圖示 🔍 展開搜尋列，支援即時關鍵字高亮、批次替換，並支援勾選「進階正則模式（Regex）」進行高效批次批改。
03

互動式表單設計與一鍵隱藏

本軟體提供完整的可填寫表單（Interactive Forms）支援，解決了傳統 PDF 表單欄位僵硬難以管理的痛點：

新增表單欄位 在「編輯」或專屬表單工具列中，選擇要新增的控制項：單行輸入框、多行文字區、下拉式清單、核取方塊（Checkbox）或送出按鈕，拖曳至指定位置。
一鍵切換「隱藏/顯示表單」 在次級工具列中點擊 👁️ 隱藏互動式表單，即可瞬間將所有表單外框與預覽隱藏，回歸純淨文件檢視；再次點擊即可恢復互動輸入。

* 貼心設計：表單輸入框內建智慧失焦防護機制，在點擊輸入時不會發生游標意外跳出或無法連續輸入的問題。

04

電子簽章、核准印章與批註審閱

  • ✍️
    手寫觸控電子簽名： 點擊切換至「🖍️ 註解與簽名」模組，按下「✍️ 電子簽名」。系統提供流暢的手寫畫布，您可以用滑鼠或觸控筆親筆簽名，完成後可選擇筆跡顏色並自動透明去背存為常駐簽章，下次即可一鍵直接蓋在合約末端。
  • 🔏
    商務審核圖章庫： 內建「審核通過」、「機密文件」、「急件處理」、「作廢無效」等專業印章，支援自訂文字與蓋章日期，滿足公文與商務合約簽核流程。
  • 🖍️
    螢光筆與畫線標註： 提供黃色、綠色、粉色螢光標記筆，支援自由手繪劃記與便條紙註釋，所有標記均會自動彙整於左側抽屜的「註解列表」。
05

離線神經網絡 OCR 繁中識別與框選辨識

ProPDF Studio 打破了傳統 OCR 辨識需要付費上傳雲端的隱私疑慮，軟體直接內建了 13MB 官方頂級 tessdata_best 繁體中文深度學習權重模型。此外，針對手寫稿、草書或複雜表格，更內建支援 Google Gemini 雲端視覺大模型（預設模型為 gemini-flash-lite，並開放使用者自行輸入任意 Gemini 多模態模型名稱）。

如何使用 OCR 功能：

1. 點擊頂部模組列的「🔍 掃描轉文字 (OCR)」。

2. 選擇辨識語言（預設為「繁體中文 + 英文」）。

3. 全頁辨識：點擊「⚡ 開始全頁 OCR 辨識」，系統自動進行 2x 超解析度放大與自適應二值化去底色，完成後將內文轉換為可編輯之文字區塊。

4. 局部區域框選辨識：若只需要提取表格或局部圖段，請使用「🔲 框選區域辨識」，在圖檔上拉出矩形框即可精準提取該區域文字！

5. AI 視覺引擎設定：點擊「⚙️ OCR 增強與 AI 引擎」，可切換為雲端視覺 AI，輸入 API Key 後可自訂模型（預設為 gemini-flash-lite，亦可自由輸入其他模型），兼顧極致隱私與最高識別準確率。

06

防誤觸 F5、自動暫存災難復原與安全密碼

🛡️ 自動暫存與 F5 誤觸攔截 每次編輯操作後 1.2 秒內，系統無感寫入 IndexedDB 本機資料庫。當您不小心誤按鍵盤 F5 或 Ctrl+R 時，軟體會立即彈出確認防護對話框；即使電腦意外重啟，頂部會顯示「⚡ 立即還原草稿」藥丸，點擊立即恢復最後編輯狀態。
🔒 雙層密碼安全體系（開啟密碼 vs 權限密碼） • 開啟密碼 (User PW)：設定後，啟動保護時會自動遮蔽頁面並呈現安全解鎖關卡，輸入正確開啟密碼後才能檢視頁面。
• 權限管理密碼 (Owner PW)：設定後可用於解鎖以下被勾選限制的操作，確保公文與機密合約不被竄改。
🚫 四大實質權限強制攔截機制（點擊受限項目自動彈出解鎖對話框）：
• 另存 PDF / 檔案匯出：未獲授權時禁止另存 PDF、Word、Excel 及系統列印。
• 頁面整理：未獲授權時禁止插入新頁、旋轉角度、刪除或拖曳重排頁面。
• 註解與簽名：未獲授權時禁止新增手繪簽名、審核印章、螢光筆及便利貼。
• 內文修改與複製：未獲授權時禁止雙擊修改文字框、編輯表單及 Ctrl+C 複製。

常見問題解答 (FAQ)

Q1：三個下載版本有什麼差別？我應該下載哪一個？ ▼
• 單一檔案執行版（最推薦）：只有一個獨立的 .exe，不需要安裝也不用解壓，雙點即可運行。
• 綠色免安裝 ZIP 版：適合放在隨身碟（USB）隨插即用，解壓縮後直接執行。
• Windows 安裝版：適合希望在桌面建立圖示捷徑與開始功能表的使用者。
Q2：使用 OCR 功能時需要連上網路或額外下載語言包嗎？ ▼
不需要！ 本程式已將官方最頂級的 13MB 繁體中文深度學習模型（chi_tra.traineddata）及英文模型完整打包在程式內部。無論是在無網路的飛機上、保密內網或機房，都能 100% 離線秒速辨識，機密文件絕不外流。
Q3：匯出的 PDF 會出現排版走位或邊界多出大片空白嗎？ ▼
不會！ ProPDF Studio 採用高規格向量 1:1 等比 A4 輸出技術（595.28px × 841.89px 精確映射至 210mm × 297mm 印刷規格），並已徹底修正傳統列印視窗中右側與下方的留白問題。
Q4：如果編輯到一半不小心按到 F5 或電腦當機怎麼辦？ ▼
不用擔心！軟體內建「自動暫存防護機制」，每次編輯 1.2 秒內會自動存入本地高容量 IndexedDB。若誤按 F5 會主動攔截提示；若強行重開，工具列頂部會出現「⚡ 立即還原草稿」藥丸，點擊即可瞬間找回所有編輯內容！
