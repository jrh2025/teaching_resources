FAQ

常見問題解答

關於安全性、隱私與操作的常見疑慮說明

Q1：點擊「抹除 LocalStorage」會影響我的書籤或已存密碼嗎？ ▼
完全不會。 LocalStorage 是專門供前端網頁儲存臨時變數（如外觀主題、網頁版快取的 API 金鑰）的獨立資料庫。您的瀏覽器書籤（Bookmarks）、瀏覽歷史（History）以及 Google 帳號儲存的帳密（Login Data）存放在完全不同的獨立檔案中，抹除 LocalStorage 絕不會遺失書籤或密碼。
Q2：啟動時若 Windows Defender SmartScreen 出現警示怎麼辦？ ▼
這是正常現象。因為本工具為純本地開源 PowerShell 腳本，未向商業機構購買數萬元的企業程式簽章憑證。若彈出 Windows 保護提示，請點擊 「其他資訊」 -> 點擊 「仍要執行」 即可放心使用。
Q3：如果不小心誤刪了檔案，還能復原嗎？ ▼
可以。 系統在執行抹除或隔離時，第一時間均會自動在 Quarantine_隔離區 建立還原存檔點。您只需切換至「隔離保護區與復原中心 (Rollback)」頁籤，點擊 【🔄 一鍵全數復原】 即可將所有檔案原位還原。
Q4：本工具會不會把我的電腦資料或金鑰上傳到網路上？ ▼
絕對不會。 本工具採用 100% 離線本地運算架構，腳本原始碼完全開放透明，沒有包含任何對外連線的程式碼（無 Telemetry、無分析回傳），即使您將電腦網路斷開，所有健檢與清除功能依然能 100% 正常運作。
